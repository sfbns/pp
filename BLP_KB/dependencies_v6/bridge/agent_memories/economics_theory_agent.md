## Controller acceptance gates

### Gate 1 — object

- [inference] Pass only if familiar object, corrected object, and relevant counterfactual are explicit.
- [inference] Reject if the “contribution” is an added variable that leaves the decision/welfare object unchanged.

### Gate 2 — foundation

- [inference] Pass only if the benchmark result and its fixed primitive are stated.
- [inference] Reject a named theory that leaves all beliefs, constraints, actions, prices, and equilibrium conditions unchanged.

### Gate 3 — institution

- [inference] Pass only if the treatment, actor, timing, gatekeeper, and avoidance margin are feasible and sourced.
- [inference] Reject a clean model built on a nominal policy that differs from realized exposure.

### Gate 4 — mechanism

- [inference] Pass only if the chain is shock/rule → information/constraint/incentive → agent action → market/institution response → outcome.
- [inference] Reject any arrow whose subject, direction, or timing is missing.

### Gate 5 — prediction and rival

- [inference] Pass only if the proposition/hypothesis contains a sign, threshold, state, footprint, or policy ranking plus a closest-rival contrast.
- [inference] Reject average-effect prose when the model predicts a sign switch.

### Gate 6 — observable and identification

- [inference] Pass only if direct measures, proxies, generated objects, estimand, variation, and allowed wording are separated.
- [inference] Reject proxy → primitive, decomposition → mediation, fit → identification, local effect → equilibrium welfare, and private loss → lobbying causality upgrades.

### Gate 7 — model necessity

- [inference] Pass only if every model block is required for a sign, equilibrium feedback, latent-object recovery, counterfactual, or welfare object.
- [inference] Reject structural or BLP complexity used as status display.

### Gate 8 — prose and provenance

- [inference] Pass only if the seven-sentence block preserves upstream conditions and the source/evidence ledger.
- [bridge-card synthesis] Reject any exact equation, theorem, page, table, or quotation derived only from the bridge card.

## Conflict-resolution protocol

1. [inference] **Theory sign versus empirical contrast**: if the model gives a conditional sign but the design estimates only an average, narrow the hypothesis to the estimable contrast or redesign; never erase the condition.
2. [inference] **Institution versus model action**: if agents cannot legally or technologically take the modeled action, revise the action set before estimation.
3. [inference] **Identification versus rhetoric**: if evidence is mechanism-consistent rather than causal, the weaker wording wins.
4. [inference] **Structural ambition versus data**: if additional primitives lack moments or variation, retain a conceptual/formal proposition and drop quantified counterfactual claims.
5. [inference] **BLP extension versus residual quality**: if policy, credit, network, beliefs, or attention is observationally inseparable from xi_j, do not claim a separately identified extension.
6. [inference] **Benchmark preservation versus novelty rhetoric**: state what the benchmark still identifies or when it remains valid before explaining the corrected object.
7. [inference] **Source precision versus memory convenience**: reopen the original source or remove exact formal/bibliographic precision.
