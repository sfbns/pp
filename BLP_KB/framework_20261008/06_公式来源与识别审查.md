# 公式来源、识别与模型审查账本

## 二、当前模型中不能独立自由估计的组合

| 参数或变量组合 | 为什么有风险 | 推荐处理 |
|---|---|---|
| gamma × 学习权重 × 里程/期限尺度 | 都可以改变标签响应幅度 | 外部固定使用尺度；受限两来源或识别区间 |
| 品牌×月固定效应＋品牌×月均分 | 精确列共线 | 控制质量与估计口碑二择主目标，或寻独立曝光变异 |
| 标签变化＋有向道路差变化 | 固定道路值时二者反号相等 | 不能称独立两机制；需要信念／校准异质性 |
| 总评分＋其所有分项完整效用 | 可能同信息重复、甚至精确共线 | 总分替代分项，或明确额外独立渠道 |
| 容量、能耗、续航的对数 | 相同计量边界下存在恒等关系 | 工程桥梁＋少数真正服务属性；检查秩 |
| 风险厌恶＋任意未知主观方差 | 多以乘积进入选择 | 有外部方差证据才量化风险；否则情景分析 |
| 出行缺口的chi和omega整体水平 | 乘法尺度不识别 | 固定omega在参考充电情景等于1 |
| gamma与完全自由的个体偏好协方差 | 聚合份额难以约束 | 从共同分类型gamma和有限随机系数开始 |
| 企业年度固定效应＋总专利年度因变量 | 企业年只有一条总数时完全饱和 | 技术相对方向面板，或另估总量模型 |

## 三、需求方向必须满足的限制

1. 预期能源成本增加，价格、信念权重、风险与所有其他选项固定，且gamma正，则自身效用下降。gamma等于0.2也成立，不能据此证明不短视。
2. 标签提高、主观成本下降可以来自新来源纠正悲观先验。必须验证旧先验/来源权重，不得根据正系数临时选故事。
3. 若均值成本上升，风险溢价下降可以抵消，但原始评论方差并非主观风险。
4. 若所有BEV效用不降、其他选项效用不上升，固定价格与选择集下BEV总份额不降。固定寒冷条件只改变幅度，不能凭空反转该单调性。
5. 共同提高对各车未来费用的权重可以有利于较低费用BEV；只提高BEV自身电费权重反而直接降低其效用。
6. 比例重标加对数续航不会自动降低电池容量的边际效用；创新弱化需额外饱和、阈值或成本回报机制。

## 四、来源核对中发现并保留的修正

- 使用真正发表于1995年的 `blp.pdf`；另一份标题含1995的93页文件实际为1993年工作稿。
- BLP的xi是研究者未观察，不是消费者对真实技术的一切无知。
- Xing等2021原文条件于已经决定买新车，不含“不购新车”外部选项；可借其替代思想，不能复制其第二选择资料或外部采用结论。
- 食品标签上传15页文件是补充材料；主文另从作者机构网站核对。原文使用独立信念调查，不能忽略这项识别条件。
- Gillingham正式版的0.16—0.39与2019工作稿0.15—0.38分开，不混用版本。
- Durrmeyer上传为2021作者稿，Leard上传为2017稿，Grieco上传为2023作者稿。本文没有把所有旧稿方程或数值称为最终版。
- 部分最新论文仅核元数据/摘要，明确没有借用未读的函数或定量结果。

## 五、第三方与数值审查的范围

本次配套的50项检查是可复现的**数学与人工数据自检**，不是独立经济学家审稿或第三方agent的通过认证。此前第三方文献检索返回的无关片段不作为本次审查依据。尚待真实数据核验的内容包括：工具外生性、原始标签历史、车型版本一致、评论选择与来源接触、主观信念/风险、政策后的价格/技术反馈和创新的因果归因。
