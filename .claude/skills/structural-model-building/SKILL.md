# 结构模型构建

中国工况项目先加载 `references/current-project-adapter.md`，恢复本轮输入、政策时钟、纠错优先级与未完成评审；历史PASS不认证当前版本。

**结构模型不是"更高级的回归"，是把观测结果翻译回经济原语、再用原语回答观测不到的问题。** 它的收益全部来自反事实、福利与均衡传导；它的成本是每一条设定都变成一个可被拒绝的假设。

## 第零道门：先选最省力的一层

六层递进：简约式因果或描述 → 会计分解 → 充分统计量 → 部分识别的界 → 静态均衡结构 → 动态、空间或网络结构。**用能回答问题的最低一层，只有缺失的边际会实质改变目标对象时才往上走**；能用界回答政策排序时，不要拿一个方便的函数形式代替部分识别。每个原语贴七类标签之一：直接观测、已识别、集合识别、校准、借用、归一化、只在反事实中出现。见 `references/when_and_which_model.md` 第 0 节（来源是用户专家包 `D:\codex\economics_theory_agent_complete_gpt55_xhigh\kb\08_hypothesis_packaging_45\agent_memories\structural_professor.md` 第 3、6 节）。

## 第一道门：该不该上

只有当下面至少一条成立才上结构层：

1. 要的对象是**替代矩阵**——谁被谁替代、政策改变的是配置而不只是总量；
2. 结果与其他市场对象**联立**（价格、属性、进入、网络、库存），reduced-form 漏掉反馈回路；
3. 要做**样本外或制度外的反事实**——一个从未实施过的政策；
4. 要**福利与归宿**，而不只是效应大小；
5. 要把一个政策讨论里被当作已知的**参数本身**估出来。

要的只是平均处理效应、或数据只支持一个可信的准实验对比，就**不要上**。设一个"结构模型更严谨"的默认是错的：**结构方程不会因为更复杂而自动产生政策因果识别。**

## 第二道门：三个必须先答的问题

答不上就别写效用函数。

- **原语是什么？** 偏好、技术、信息、约束、博弈规则，逐项点名。
- **谁内生？** 价格、属性、进入退出、网络、暴露强度——名字先点出来，识别策略才有靶子。
- **outside option / 状态空间边界在哪？** 只观察到内部份额，你估的就是条件需求，算不出边界上的替代与福利。

## 第三道门：机制落在哪个原语上、要什么理论

写任何机制之前先定落点：效用里的货币项、偏好异质性、误差结构、选择集、信息与信念、厂商的第二个选择、产品间外部性、规制约束、动态状态。**落点决定它移动哪个参数**（例：残值进广义价格、改截距；信号可信度可改信念对显示数字的权重；交易信任也可能产生独立风险/兑现成本，二者不能只凭一个信任系数混同），也决定需要哪一类理论（现值资本化、分选、曲率与转嫁、多属性质量选择、网络外部性、conduct、贝叶斯更新与不注意、动态选择）和哪一种独立变化。
每条候选渠道都要写出一个**与明确rival有不同联合限制**的检验特征，再把异质性写成对手假说之间的判别检验。度量口径类冲击先过"表示不变性基准"。
见 `references/mechanism_construction_and_theory.md`；BLP 里的逐篇实例见 `blp-model-building/references/extension_genealogy.md`。

## 模型类选择

见 `references/when_and_which_model.md`。一句话路由：
静态差异化产品 + 要替代与均衡 → **BLP/RC logit**（走 `blp-model-building`）；
残余分组相关 → nested logit / RCNL 作稳健性，**不得只因研究焦点是动力类型就预设 nest；有独立替代证据时可把该树作为候选，检验其限制**；
跨期状态依赖与不可逆决策 → 动态离散选择；
异质个体 + 不完全市场 + 一般均衡 → Bewley/Aiyagari 类（走 `aiyagari-model-homework`）；
矩可写但似然不可写 → GMM；似然可写 → MLE；两者都不可写但能模拟 → SMM；
度量口径或标签信息改变 → 信念增广离散选择（缺独立变异/先验尺度约束时只报复合权重；微观矩非必要，已知先验/尺度加独立aggregate排除与联合满列秩可条件识别参数，仍不自动识别心理命名）；补贴或税的转嫁 → 明确成本/供给conduct与需求曲率，必要时放松收入效应函数形式；耐用品跨期替代与退出 → 动态离散选择（贴现因子要固定或有排除变量）；产品间网络外部性 → 给定网络时可估条件需求；仅在estimand含内生网络/进入反馈时另建相应均衡或进入方程；进入退出与市场结构 → 静态进入博弈，多重均衡时用矩不等式给界；动态博弈 → 两步法；拍卖 → 从出价分布反推估值；生产函数与加价 → 代理变量法与生产法加价；匹配 → 可转移效用匹配；空间与贸易 → 量化空间模型。

## 估计配方

BLP 走 `blp-model-building`。其余见 `references/estimation_recipes.md`：开工前的账本与固定抽样、GMM 两步法与 Hansen J（J 不拒绝不证明工具有效）、弱识别诊断、模拟矩的 `(1 + 1/S)` 方差放大及其适用条件、动态离散选择的嵌套不动点与两步 CCP 法（含 Hotz–Miller 估值公式）及贴现因子识别、两步法博弈的推断、校准与借用参数的标注，以及进入、动态博弈、拍卖、生产函数与加价、匹配、量化空间六类模型族各一条最小配方（第 7 节）。关键结论由 `scripts/structural_selftest.py` 复现（当前17条检查，含 CCP 估计、GPV 反推估值、DLW 加价，本机 ALL PASS）。

## 建模序列（每一步都要能单独交付）

1. 锁定 estimand：把"总效应""组内重配""跨组替代""机制""均衡反馈""福利"分别写清楚，**不要合成一句话**。
2. 定义单位、市场、产品、outside 与市场规模 `M`。
3. 建立政策暴露：区分**法定资格 / 实际采用 / 对外展示**三个状态，用处理前预定的量构造暴露，**绝不用处理后的销量、价格或工程结果定义工具**。
4. 建立**真正嵌套的受限基准**：把完整模型的类型分布退化到一个预定代表类型，而不是"把非线性个体变量先取均值再代入"（`G(E[ω]) ≠ E[G(ω)]`）。取均值的版本只能叫 `mean-index approximation`。
5. 释放异质性，得到主模型。
6. 逐参数登记识别（变化来源 / 排除变量或微观矩 / 有效支持 / rival channel / 局部秩）。
7. 只有在需要时才加供给或动态层，且每加一层都要有对应的额外识别信息。
8. 反事实：先登记状态向量（改什么、固定什么），共用同一组随机抽样。
9. 福利：决策效用与规范经验效用分轨；账户不闭合就不出总额。
10. 全流程审计与 bootstrap，冻结并出哈希。

## Claim ladder（说到哪一级就只能写到哪一级）

见 `references/identification_and_claim_ladder.md`。最常被违反的几条：

- 聚合数据首先识别的是**复合响应**。没有独立变化把因子分开，就只能报复合项，并给它一个诚实的名字（"有效标签反应""有效未来成本权重"）。
- **机制不靠逐项加控制变量**。总效应回归里加入处理后变量会切断机制并引入 post-treatment bias。正确顺序是：先估总效应 → 再把每个中介**单独作为 outcome / 第一阶段** → 最后在结构反事实里关闭单个通道。
- **样本内拟合不是验证**。份额反演在同一市场内令 `s^model = s^obs`，把反演出的拟合值再送回简约式只是机械复制数据。合格验证要么用政策反事实模拟后跑**同一个** reduced-form 算子作差，要么用留出市场预测。
- **2026-09 新增的五种越级**：连续剂量当对照组 · 企业申报定义的处理时点（存活标记）· 复制结果变量造样本 · 渠道放错原语 · 同一批数据既估结构又当独立外部矩。见 `references/identification_and_claim_ladder.md` 第 8 节。
- **数字不可移植**：别国别样本的条件关联（弹性、阈值、换算因子）只能作测量动机，不能定标本项目。

## 输出

交付顺序：推荐的研究问题与 estimand → 制度时点与数据单位 → 暴露构造 → 受限基准 → 主模型 → 逐参数识别 → 供给/动态层 → 机制与异质性 → 反事实 → 福利 → 一致性检验 → 失败模式 → **最小数据决策树**。
写作与用词见 `references/writing_and_delivery.md`。
**停止条件**：缺市场规模、outside share、成交价、产品级结果或必需微观矩时，明说"最强可辩护版本是什么、缺哪块数据卡住了下一层"，不要用复杂数值替代缺失的数据变异。
