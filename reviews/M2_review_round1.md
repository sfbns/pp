## 3. 总体评价

**主要优点**：
1. 对象分离清楚。L（标签）、T（真实）、B（信念）分开处理；"差距缩小"作为客观的认证信息偏差收敛，与它是否经信念改变需求是两件事，这条主线符合项目技能的命名规则（"认证信息偏差收敛"不等于信念校准改善，也不等于信任或欺诈）。
2. 信念由正态共轭贝叶斯更新从零推出。双信源后验 (M2.7)(M2.8) 和比较静态 (M2.9) 全部正确；需求效应经 $\gamma K B$ 进入广义价格，没有另加一个"差距特征"造成重复计价，与 M1 的嵌套关系清楚：$\kappa=1$ 时回到 $\varphi=\gamma\zeta$。
3. 用户关心的"标签上浮多少需求才不降"给出了显式闭式 (M2.16)，代数正确，并且指出没有可信度变化时 $W^*=0$，不凭空制造容许度。
4. 对"欺诈"一词的使用克制，只用于有证据的故意误报，不用来命名政府的工况改革。CARA 风险项不与均值项重复计价；M2-B 主动承认依赖函数形式。
5. 可证伪预测表（精度梯度、时点、BEV 反向）有实质内容。

**主要问题**（详见第 5 节）：
1. (M2.5) 锚定解释符号错误。
2. 加法偏差与比例偏差两套原语混用：表示不变性基准、(M2.21)、$W^*$ 三处互相不一致，且与 M1 不一致。
3. "需求上升"条件只考虑自身效应，命题 M2.2 的必要性表述错误；漏掉第三条路径，也漏掉"相对可信度"这一系统渠道。
4. 识别部分没有说明 M2-A 的校准等于施加了表示不变性，没有给 $m$、$n_j$ 的工具，没有核验固定效应残差化后的支持。
5. "可信度红利"和"理性怀疑""信任"三个命名在经济学含义上越级或混淆；BEV 的贝叶斯期望损失漏掉了方差渠道。

### §M2.6 BEV 反向情形

- **(M2.17)(M2.18)** ✓ 代数已验证。⚠ (i) "口碑与媒体**揭示** CLTC 更宽松，$\hat\beta^R_1-\hat\beta^R_0>W^R$"：理性揭示意味着 $\hat\beta^R_1-\hat\beta^R_0=W^R$，平均车型的第一项为 0；信念下降需要**过度反应**。理性情形只经 $\kappa$ 渠道或车型偏离 $W_j-\bar W$ 起作用，两者必须区分。(ii) 冬季续航损失主要属于情景方差 $\mathrm{Var}_z$（M2.2），除非冬季损失因车型而异（如是否配热泵），否则不是跨车型标签噪声 $\tau^2$，应写明。(iii) $\kappa^R_0,\kappa^R_1,\hat\beta^R_s$ 缺 $j$、$d$ 下标，与 (M2.17) 不一致。(iv) CLTC 同时改变电耗标签 $L^E$；同一测试产生的续航与电耗误差相关，应做二元正态联合更新。

### §M2.8 识别

- **(M2.21)** ✗ "把感知偏差**写成**比例形式 $L+\hat\beta=\zeta L$"不是改写，而是**换了一个模型**：偏差与标签成比例。若 $\hat\beta_{d,s}$ 为常数，$\zeta$ 就会随车型变化。§M2.4–§M2.5 的全部结论（R1、表示不变基准、$W^*$）都是在加法常数 $\hat\beta$ 下推出的，必须在 $\zeta$ 形式下重推；或者论证加法形式可估，并估加法形式。噪声也要相应说明：若 $\zeta L=T+\eta$，则 $\mathrm{Var}(L\mid T)=\hat\tau^2/\zeta^2$。
- **(M2.22)** ✓ 系数映射、M2-A 与 M2-C 的反推公式均已用 sympy 验证。⚠ (i) **M2-A 的校准 $\zeta_{d,s}=\overline{(m/L)}_{d,s}$ 机械地施加了表示不变性**：同硬件模拟中 $\zeta_1=1.2037$，$\zeta_0/(1+\bar w)=1.2028$，$\zeta_sL$ 的平均变化为 0.0045，约等于 0（§7.2[7]）。因此 M2-A 中 R1 被构造性排除，任何"红利"都被迫归入 $\Delta\kappa$，$\kappa$ 的估计还会吸收 $\zeta$ 设定错误。文中没有说明这一点。(ii) M2-A 每个动力有 4 个约化系数、3 个结构参数，存在过度识别限制 $\gamma_{d,0}=\gamma_{d,1}$，可以检验，文中未提。(iii) M2-B：$1/a^R=1/\gamma+v/(\gamma\hat\tau^2)$（sympy 已核）。"$v$ 取两个不同值即点识别"是把产品层面的 $a^R_j$ 当成可观测量的映射论证。BLP 中识别要经含 $\xi$ 的矩条件实现，而 $n_j$（从而 $v_j$）是内生的（累计评论数约正比于累计销量，进而与过去的 $\xi$ 相关），也存在测量误差（有效评论数）。表中"全部识别"应改为"条件识别"。(iv) **$m$ 的内生性**：例如性能取向、偏重的车型油耗高、$\xi$ 也高，这时 $K\cdot m$ 不能当作外生的包含变量，文中没有给工具或排除论证。(v) **固定效应残差化后的支持**：在产品（谱系）固定效应和"动力×市场×月"固定效应下，只剩"$K$ 的时间变化 × 截面差异"以及个体异质性可用。模拟显示：油价时间 sd 为 10% 时，$K\cdot L$ 的残差方差份额为 0.7%；sd 为 1%（类似 BEV 的电价）时只剩 0.01%。$\mathrm{corr}(L,m)$ 从 0.82 升到 0.996 时，缩放后的条件数从 3.1 升到 21.3（§7.2[6]）。文中也没有交代评论数据的层级（配置级还是谱系级）：若只有谱系级评论，$K\cdot m$ 基本被谱系固定效应吸收。
- **§M2.8.2** ⚠ "同硬件跳变……提供 $a^L_{d,1}$ 的**尖锐**识别"没有考虑展示时点由企业选择（BEV 可自愿切换）、切换与改款捆绑（项目记忆称之为"头号威胁"）以及同期补贴变化，至少应援引 M1 的 $Z^W$ 工具与同配置样本。

### §M2.9 命题与命名

- **命题 M2.1** ✓ σ-代数论证正确；纯平移情形的等价关系也正确。⚠ $c_1\ne1$ 时，加法模型需要重标噪声（$\hat\tau_1^2=c_1^2\hat\tau_0^2$），"精度不变"只适用于 $c_1=1$，而经验上相关的恰恰是比例换算。

- **命题 M2.3** ✓ 对信念正确、价格与选择集固定的贝叶斯决策者，Blackwell 结论成立。⚠ 必须说明是决策效用还是体验效用：$\gamma\ne1$（存在内部性）时，Blackwell 只保证决策效用的事前期望不降，不保证体验福利；同时给出准确引用（Blackwell 1953, *Ann. Math. Stat.*）或证明概要。
- **命名** ✓ "认证信息偏差收敛"指客观的 $\beta$ 与 $\tau^2$；"欺诈"的使用受限。⚠ (i) 把 $\kappa$ 称作"信任"越级，应称"标签精度权重"，"信任"只作解释并附证据要求。(ii) "可信度红利"混淆了"纠正过度怀疑"（信念校准改善）与"新增轻信"（校准恶化）两种情形。(iii) 文中把 gaming 只当作车型离散 $\eta$ 的来源，与 RS 的证据相反：RS 发现 gaming 表现为整体平移，主要进入 $\beta$。(iv) Kamenica–Gentzkow（2011）的引用偏离主题：这里没有发送者优化。若要用，应把"政府选择测试工况"明确建模成信息结构选择。

## 6. 建议修改项

1. **零楔子切换车型的判别检验**：同硬件、楔子 $W_j\approx0$ 却换了新口径标签的车型。天真模型预测零效应；可信度渠道（$\Delta\hat\beta$、$\Delta\kappa$）预测非零效应。项目已有"BEV 46 组配对中位数为 0"的样本，正好可用。
2. **$K$ 梯度证伪**：可信度效应应按 $\alpha\gamma K$ 放大，即随里程与油价增强；标签格式或显著性带来的效应不会随 $K$ 变化。建议把这一条加入 P-M2 表（M1 的 P3 对应它）。
3. **学习动态**：令 $\hat\beta_{d,1,t}$ 随累计的 WLTC 口径评论更新，使 P-M2-3 的"效应衰减"成为模型预测，同时提供时间维度上的识别变异。
4. **$\kappa$ 的异质性**：设关注型与不关注型两类消费者（有限混合或随机系数），与"有效评论数"呼应，也可借替代模式辅助识别。
5. **特征条件先验** $T_j\sim N(x_j'\pi,\sigma^2)$，替代仅以动力为条件的先验。
6. **BEV 的 $(L^E,L^R)$ 二元联合更新**；PHEV 用向量信号更新。
7. **分解的顺序稳健性**：(M2.11) 报告两种排序及其平均（Shapley）。
8. **$\kappa=1$ 的边界推断**：嵌套检验采用 $\bar\chi^2$ 零分布。
9. **理论锚点补充**：Frankel & Kartik（2019, JPE）、Kartik, Ottaviani & Squintani（2007, JET，"credulity"）、Jin & Leslie（2003, QJE，卫生评级卡与需求）。GHVB 卡 §10 关于信任的讨论（统一的加法折扣在 GPM 差分下不影响结果，比例高估则会影响）可直接用来论证加法与比例的选择。
10. **(M2.5)(M2.6) 的样本与处理**：用原始评论均值并按 $n$ 加权；只用同硬件配对；精度回归扣除 $\sigma_u^2/n_j$。
11. 把"$\gamma$ 不随工况改变"写成维持假设，并用 M2-A 的过度识别检验它。
12. **跨动力汇总**：$\Delta S_d\approx\sum_{j\in d}\Delta s_j$，逐一写出天真、表示不变、可信度三种信念情形下 ICE↔BEV 的流向（含 outside）。
13. **估计约束**：报告 $a^L,a^R>0$、$\kappa\in(0,1)$ 是否被数据违背，违背时如何处理。
14. **CARA**：说明 $\gamma$ 放在风险内还是风险外，并从 $\mathcal V$ 的二阶展开推出 CARA 项。
15. **目标 $T$ 的定义**：明确消费者相关的驾驶情景分布 $Q_m$；可利用口碑中的车主城市构造 $m_{jm}$，使其与城市—月市场匹配。

```python
import numpy as np, sympy as sp
# [1] (M2.5) 锚定方向
rng=np.random.default_rng(20261008); J,T=400,24
w=rng.uniform(.02,.14,J); lnT=np.log(rng.uniform(5,9,J)); lnLN=lnT-np.log(1.3); sw=rng.integers(6,18,J)
def est(rho):
    S=(np.arange(T)[None,:]>=sw[:,None]).astype(float); lnL=lnLN[:,None]+S*w[:,None]
    y=(1-rho)*lnT[:,None]+rho*lnL-lnL+rng.normal(0,.01,(J,T))
    dm=lambda v:(v-v.mean(1,keepdims=True)-v.mean(0,keepdims=True)+v.mean()).ravel()
    X=np.column_stack([dm(S),dm(S*w[:,None])]); return np.linalg.lstsq(X,dm(y),rcond=None)[0]
print([est(r).round(3) for r in (0,.3,-.3)])   # pi1 ≈ -1, -0.7, -1.3
# [M2] 比例规格下的 W*
k0,k1,z0,z1,LN,W,m,wb=sp.symbols('k0 k1 z0 z1 LN W m wb',positive=True)
Ws=sp.solve(sp.Eq(k1*z1*(LN+W)-k0*z0*LN-(k1-k0)*m,0),W)[0]
print(sp.simplify(Ws), sp.simplify(Ws.subs({k1:k0,z1:z0/(1+wb)})))  # RI: W*=wb*LN
# [3] 命题 M2.2 反例
print(0.5*(0.5+0)+(0.2-0.5)*2.0)   # -0.35 < 0
```
