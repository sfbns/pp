## Stable BLP Memory
- 这一批论文共同的核心，是把产品差异化需求恢复成可以做替代、价格、政策和福利比较的结构对象。
- 经典主干仍然是：消费者离散选择 -> 市场份额 -> 价格/属性内生性处理 -> 供给侧定价或均衡恢复 -> 反事实 / 福利。
- 变体主要沿三条线展开：需求侧更轻的离散选择版本、带显式供给/进入的均衡版本、以及把网络效应/标签/属性设计接进 BLP 的扩展版本。

## Identification Memory
- 这批论文最常见的识别入口有三类：价格内生性的工具变量 / GMM，自然实验或制度冲击，和利用政策变化做结构化反事实。
- 当论文不能直接观察福利时，作者通常先恢复需求弹性或边际成本，再把均衡变化映射成消费者福利、企业利润和社会福利。

## Counterfactual Memory
- 反事实高频主题包括税收、补贴、禁令、标签、市场进入、平台扩张、基础设施网络和地方保护。
- BLP 模型在这些论文里的真正价值，不是“估计一个需求系统”，而是回答“如果改政策，替代链条会怎么动，福利又会如何重新分配”。
