# BLP Writing Synthesis

## Story Ladder
- 顶刊 BLP 论文常见的引言逻辑是：先提出一个现实市场或政策争论，再指出 reduced-form 很难回答替代、均衡和福利，最后自然过渡到结构模型。
- 论文很少把“我们用了 BLP”当成卖点本身；真正的卖点是：这个结构模型让作者能回答一个别的方法回答不了的问题。

## Section Logic
- 高频顺序是：Introduction -> Background / Data -> Model -> Identification / Estimation -> Results -> Counterfactual / Welfare -> Conclusion。
- 数据和制度背景通常放在模型之前，其作用不是铺陈素材，而是为模型设定、市场定义和识别假设做前置正当化。

## Reusable Moves
- 先把政策问题讲成“需要替代矩阵”的问题，再引出结构模型，而不是直接从方法开始写。
- 让模型章节回答两个问题：为什么这个模型适合当前市场，为什么它能支撑后面的反事实。
- 结果章节先讲机制和弹性，再讲福利和政策含义；福利不是附录式补充，而是全文的终点。
