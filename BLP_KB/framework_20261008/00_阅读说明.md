# 交付阅读顺序

**首先阅读完整稿的“执行摘要”和第1、10、13章。** 它们固定问题、纠正用需求方向判断短视的逻辑，并给出一个不依赖已有家庭购买调查的受限共同估计路径。

- `01_完整研究框架与逐式推导.md / .pdf`：主稿，34页、23章及2个附录，107个带编号的公式块。PDF为XeLaTeX排版；Markdown保存全部LaTeX源公式。
- `02_详细思维导图.md`：四张图的完整文字大纲，149个节点；另附8页打印版PDF。
- `03_离线可折叠思维导图.html`：浏览器直接打开，支持页签、折叠和搜索，无需网络。
- `03_完整课题思维导图.xmind / .mm`：XMind XML格式与FreeMind备份；已检查归档与XML结构，没有在XMind桌面应用中实测。
- `04_公式数学核验.py`：50项可复现代数和人工数据检查，运行环境为Python＋numpy/scipy/sympy。
- `05_数学核验结果.md / .json`：实际执行结果；数学通过不等于真实数据识别通过。
- `06_公式来源与识别审查.md`：公式来源属性、不可同时自由识别的参数与修正记录。

主稿中的[R1]—[R23]及[P1]—[P3]对应第21章文献与制度来源账本。没有在包内再次复制受版权保护的论文全文，原始上传档案不变。

主数据始终按市场—车型—年月处理。模拟消费者不意味着已经有家庭调查。风险、主观信任和动态创新模型是明确受额外信息约束的扩展，不作为已经估计出的事实。
