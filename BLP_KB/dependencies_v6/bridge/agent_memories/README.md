# Private specialist memories

This directory contains one durable memory per custom economics specialist. The files are private in the operational sense: each agent is instructed to load its own synthesis first, while the active expert may inspect any file when adjudicating conflicts.

Each memory must contain:

- the decisions owned by that specialist;
- question-led retrieval cues;
- paper-card exemplars with source lineage;
- reusable reasoning or packaging moves;
- failure modes and evidence boundaries;
- a handoff contract to the next specialist;
- a dated reinforcement ledger.

These memories summarize the 45 bridge cards. They do not upgrade the evidence status of the underlying papers. Normal task execution treats them as read-only. New material is promoted only after a source-linked bridge card and explicit review; never silently overwrite a specialist memory from a search result or candidate card.
