# M8.0 原则

用户要求“如果有其他机制的启发同样要给出模型推导”。本文件对每个候选机制给出：（i）它改变效用的哪一个原语；（ii）与 M2（认证可信度）、M3（资本化）可区分的预测；（iii）识别所需信息；（iv）避免重复计价的规则。基准模型每次只加入一个有支持的渠道（构造协议 [P]）。[O] 文献，[D] 推导，[P] 设定。

# M8.1 不确定性下降（风险溢价）——见 M2 §M2.7

CARA 下确定性等价成本 $CE=\gamma KB+\tfrac{a}{2}\gamma^2K^2V$，标签精度提高降低后验方差 $V=(1-\kappa)v$，即使均值信念上升，效用也可能上升（M2 (M2.19)–(M2.20)）。**可区分预测**：风险红利随消费者对车型能耗的不确定性（口碑离散度大、评论少）而增大；随风险厌恶的代理（低收入、无家充）而增大。**识别**：需要主观不确定性的度量（评论离散度只是代理）；否则只作敏感性。

# M8.2 显著性：左位数注意与整数门槛 [D]

**模型**：消费者对标签的小数部分注意不足（Lacetera–Pope–Sydnor 2012 在二手车里程中发现左位数偏差 [O·卡]；项目层提示 Kraft–Rao 2026 的左位数思路）：

$$
\widetilde L_j=\lfloor L_j\rfloor+\theta_{LD}\big(L_j-\lfloor L_j\rfloor\big),\qquad0\le\theta_{LD}\le1. \tag{M8.1}
$$

标签从 $5.9$ 变为 $6.1$（真实变化 $0.2$）时，感知变化为 $(6+0.1\theta_{LD})-(5+0.9\theta_{LD})=1-0.8\theta_{LD}$；$\theta_{LD}=0.5$ 时感知变化 $0.6$，是真实变化的 3 倍。

**可区分预测**：WLTC 楔子使标签跨越整数（$\lfloor L^X\rfloor>\lfloor L^N\rfloor$）的车型，需求下降在门槛处出现**离散跳变**；贝叶斯可信度模型（M2）中信念是 $L$ 的连续函数，不产生这种跳变。**识别**：以“跨越整数”为驱动的横截面断点设计（同一楔子大小下比较跨与不跨整数的车型），并先排除按整备质量分档的油耗门槛等制度阈值。**不重复计价**：若采用 (M8.1)，在信念中以 $\widetilde L$ 替换 $L$，不再另加“整数虚拟变量”。

# M8.3 残值渠道：标签通过二手车价格进入广义价格 [D]

二手车买家同样看官方标签，因此车辆的预期残值依赖标签：$PVR_j=(1+r)^{-H}E[RV_j\mid L_j,\cdot]$。由 M1 的广义价格 $-\alpha_i(p_j-PVR_j+\gamma K B_j)$：

$$
\frac{\partial V_{ij}}{\partial L_j}=-\alpha_i\Big[\gamma_dK_{imt}\frac{\partial B_j}{\partial L_j}-\frac{\partial PVR_j}{\partial L_j}\Big],\qquad \frac{\partial PVR_j}{\partial L^F_j}<0,\quad\frac{\partial PVR_j}{\partial L^R_j}>0. \tag{M8.2}
$$

即使消费者自己完全不计未来能源成本（$\gamma=0$），只要预期二手买家会计价，标签仍影响需求。P11 卡记录美国非特斯拉纯电每多 10 英里续航保值率提高约 5.58% [O·卡]。**可区分预测**：残值渠道在二手车市场成熟、持有期短的城市更强，且对纯电更强；资本化渠道随里程与油价增强。**识别**：城市二手车交易活跃度 × 标签的交互；或直接加入车型残值指数（若有数据）。**不重复计价**：残值是广义价格的加性项，不改变 $\alpha$；与能源成本分开列示。

# M8.4 企业披露与广告：消费者看到的不一定是官方新标签 [D]

过渡期企业可能在宣传中继续强调更好看的旧值（燃油车的 NEDC 油耗、纯电的 CLTC 续航），形成“披露楔子”。设消费者接触到的标签为加权混合：

$$
L^{shown}_{jt}=\varpi_{jt}L^{N}_j+(1-\varpi_{jt})L^{X}_j,\qquad \varpi_{jt}\in[0,1], \tag{M8.3}
$$

$\varpi_{jt}$ 为宣传中使用旧口径的比例。信息效应按 $L^{shown}$ 而非官方 $L^X$ 计算，实际跳变为 $(1-\varpi_{jt})W_j$。**可区分预测**：广告中保留旧口径越多的车型，切换时的需求跳变越小；这与“消费者理解换尺”的预测（只看楔子偏离平均）不同。**识别**：需要汽车官网、汽车之家等历史页面的口径编码（项目层建议的数据）。**命名**：这是“选择性披露”，不能升级为“实验室认证操纵”（项目层四项分解：机械换算 / 工程适配 / 测试楔子 / 披露楔子 [P]）。

# M8.5 信息外溢：改革使仍挂旧标签的车型被重新怀疑 [D]

改革公开宣传“新工况更接近真实”，等于公开承认旧标签偏低。理性消费者对仍挂 NEDC 标签的车型提高怀疑折扣：$\hat\beta_{d,0}\uparrow$，于是这些车型的信念上升、需求下降，即使其标签未变：

$$
\Delta B^{(\text{未切换})}_j=\kappa_{0j}\,\Delta\hat\beta_{d,0}>0. \tag{M8.4}
$$

**可区分预测**：改革公告后、实际切换前，旧标签车型相对已切换车型的需求下降，且下降幅度与旧标签的“美化程度”无关（是对整个口径的怀疑）；而 M3 的“注意上升”预测的是对油价敏感度上升（M3 §M3.6）。**识别**：以公告日为界的未切换车型事件研究，控制同动力共同冲击。这也提醒：用“尚未切换”车型作对照组时，对照组本身可能被处理（SUTVA）。

# M8.6 绿色光环与身份偏好：非货币效用，不是信念 [D]

部分消费者因环保身份或社会形象偏好新能源车，进入动力类型的非货币偏好 $\psi_{i,\mathrm{NEV}}$（M1 的随机系数）。它与“高估新能源经济性”（信念偏差）是两件事：前者不随电价、里程变化，后者经 $K^E$ 变化。**规则**：若只有新能源虚拟变量，绿色光环与动力偏好不可分；不能把 $\psi_{\mathrm{NEV}}$ 的大小解释为对能源成本的误判（项目层写作红线 [P]）。

# M8.7 补能网络反馈：条件需求与网络均衡 [O·卡]+[D]

M1 中补能密度 $N_{mt}$ 是给定条件。若新能源需求上升引致更多充电桩，形成反馈 $F^{N}(N,Q,z_N)=0$，则需求对改革的总效应为

$$
\frac{dS}{d\tau}=\frac{\partial S}{\partial\tau}+\frac{\partial S}{\partial N}\frac{dN}{d\tau},\qquad
\frac{dN}{d\tau}=-\big[F^N_N+F^N_QQ_N\big]^{-1}F^N_QQ_\tau, \tag{M8.5}
$$

（构造协议 D06 的隐函数接口 [P]）。只有网络进入方程被另行识别时才启用；否则所有反事实称“给定网络的条件效应”（Li–Tong–Xing–Zhou 2017 的间接网络效应文献提供该升级路径 [O·卡]）。

# M8.8 机制辨别总表

| 机制 | 改变的原语 | 关键区分预测 | 所需额外信息 |
|---|---|---|---|
| 认证可信度（M2） | $\kappa,\hat\beta$ | 精度梯度（评论越多效应越小）；差距梯度 | 车主实测、评论数 |
| 资本化/短视（M3） | $\gamma$ | 油价反应；利害梯度；贷款梯度 | 油价/里程变化 |
| 风险（M8.1） | 后验方差 | 评论离散度梯度 | 主观不确定性代理 |
| 左位数（M8.2） | 感知标签 $\widetilde L$ | 整数门槛处跳变 | 标签小数位 |
| 残值（M8.3） | $PVR$ | 二手车市场成熟度梯度；纯电更强 | 残值指数/二手交易 |
| 披露（M8.4） | $L^{shown}$ | 旧口径宣传比例越高跳变越小 | 历史广告页面 |
| 信息外溢（M8.5） | 未切换车型的 $\hat\beta_{d,0}$ | 公告后未切换车型需求下降 | 公告日、切换日 |
| 绿色光环（M8.6） | $\psi_{\mathrm{NEV}}$ | 不随电价/里程变化 | 态度数据 |
| 补能反馈（M8.7） | $N$ | 充电桩随新能源需求增长 | 充电桩进入数据 |

# M8.9 现实意义

1. **能源标签是购车者获得能耗信息的主要公共渠道。** 工况切换影响数百个车型、所有动力类型，且方向不一：燃油车标签更接近真实、插混大幅变差、纯电续航可能更宽松。理解消费者如何解读这些数字，直接关系到标签制度、油耗限值与新能源转型政策的效果。
2. **把“看到更大的数字”与“获得更有用的信息”区分开。** 同一次改革，在消费者理解换尺时几乎不改变需求，在消费者天真时造成需求转移，在可信度恢复时反而提高需求——政策评估必须知道是哪一种。
3. **纯电续航标签的可信度是当前的现实争议。** CLTC 续航在冬季、高速下与实际差距大；本课题的可信度折价模型与反事实（CF7 地区/冬季续航标签）可直接为“是否增加冬季/高速续航披露”提供量化依据。
4. **合规成本与信息效应同时发生。** 工况切换改变双积分核算，企业价格与产品结构随之调整；忽略这一点会把合规成本误判为消费者偏好。

# M8.10 理论意义

1. **在差异化产品均衡中分离“信念”与“偏好”。** 能源悖论文献长期把“消费者低估未来燃料成本”（偏好/资本化）与“消费者不相信能耗信息”（信念）混在一起。本课题用同硬件认证重标（只改信念）、油价变化（只改成本）与车主口碑（第二信源）三类变异，在 BLP 中给出二者的条件识别（M2–M3），并刻画了失败条件。
2. **公共认证作为贝叶斯信号的结构模型。** 把信任品与认证理论（信号精度、怀疑推断）嵌入随机系数需求，信任权重由感知精度与先验精度之比决定，评论数提供精度变异——连接信息经济学与产业组织结构估计。
3. **测度标准诱致的有向创新。** 标签对真实改进的“灵敏度”$\ell^c$ 与可针对性优化的空间 $b^{c\prime}$ 决定研发方向（M6 命题 M6.1–M6.2）：测度规则本身是创新激励的一部分，宽松工况会把创新引向“纸面性能”。

# M8.11 政策含义（以反事实结果为条件）

| 若反事实显示…… | 政策含义 |
|---|---|
| 燃油车可信度红利显著、体验福利上升（CF1 vs CF0） | 更真实的测试提高福利并奖励真实能效；应把“真实度”原则推广到纯电与插混标签 |
| 资本化率低且来自有限注意（M3 检验） | 提高显著性比再调数字更有效：在标签上直接显示“年燃料/电费（元）”或“五年总能源成本”（CF7） |
| 纯电可信度折价显著，北方损失大（CF2、CF3） | 推行地区化/情景化续航披露（冬季、高速），或采用更接近真实的纯电工况 |
| 差距拉大的体验福利损失大、排放上升（CF3） | 认证宽松有真实社会成本；加强一致性检查与道路抽检，压缩“纸面性能” |
| 容许上浮 $g^*$ 只在可信度大幅改善时为正（CF4） | 标签上浮可以被可信度改进部分抵消，但不能被当作“允许美化”的空间 |
| 积分成本冲击主导价格变化（M6） | 工况切换时应同步校准积分核算与目标，避免意外收紧或放松 |
| 续航门槛补贴/积分诱发“加电池”而非真实能效（M6 命题 M6.2） | 补贴与积分应基于真实能效（如冬季续航、实际电耗），而非认证续航档位 |

**总体标准**：信息政策的成功应以体验福利、技术匹配与真实排放衡量，而不是以某类车型（例如纯电）份额最大化衡量。

# M8.12 数据与执行优先序（建议）

1. **必需**：车型—月（最好城市—月）销量、成交价/指导价与优惠、在售选择集、配置谱系；三工况标签与实际展示日期（工信部公告、能耗标识备案）；油价与电价；市场规模口径。
2. **机制所需**：车主口碑的实测油耗/电耗/续航与评论数（M2 第二信源）；里程分布与家充比例（$K$、$UF$）；双积分核算与积分价格（M6）。
3. **扩展所需**：残值指数、历史广告页面、补能网络、企业专利（按 CPC/IPC 分类）。
4. **执行顺序**：M0 事实 → M1 基准 → M2/M3 机制分解 → M4 替代 → M6 供给 → M7 反事实；每一步报告识别强度与失败时的降级。
