## B. 用户目的（提炼，供每次重读时自检）

1. **先安装** BLP skill 与 agent（来自 01 包 candidate_v10 + dependencies_v6），使其可被调用；融会贯通所有记忆（演练稿、BLP1995 逐式核验底座、公式校正、45 张文献卡、燃油/工况文献卡、5 篇推荐 BLP 原文）。
2. **再推导模型**（从高级微观经济学基础—效用最大化/间接效用/随机效用—开始，到最终可估计 BLP 结构模型），覆盖：
   - M0 基础回归（事件研究/DID/RD-in-time 的结构化推导，从 logit 份额反演到线性回归）；
   - M1 **基准 BLP**（市场—年月—车型层面数据；ICE/HEV/PHEV/BEV；工况切换以什么形式进入效用——标签数值、反事实 NEDC 预测差、使用成本、续航；口碑评分如何进入：整体 vs 分项）——**目标 ≥90 分**；
   - M2 **机制一：真实—标称差距（信息/信任/欺诈的经济学包装）**：工况切换造成标称值突变 → 缩小真实与标称差距 → 信念更新 → 需求；
   - M3 **机制二：短视（资本化不足）**：可估计的"短视指标"（如未来成本资本化率/有效折现），如何与 BLP 共同估计；突变如何帮助识别；
   - M4 **NEV vs ICE 替代**（双向：燃油→新能源、新能源→燃油，都要解释；市场层面数据下的严格推导；BEV 需加电池容量与能量密度）；
   - M5 **异质性**（人口特征、地区、地貌/气候、合资 vs 自主）从模型出发；
   - M6 **供给侧**：边际成本、加成、是否促进竞争（市场势力）、**创新**（专利数据：企业—年月/年份；续航上涨是否削弱能耗比基础创新；燃油厂商燃油经济技术进步）；
   - M7 **反事实与福利**（真实—标称差距拉大的影响；差距缩小但油耗上浮多少需求不减——"需求不变的等价上浮"边界）；
   - 其他可启发机制也要给推导；
   - 现实意义、理论意义、政策含义（基于福利/反事实）。
3. **每个模型都要第三方 agent 审议**（同配置：所有 skill/agent/文献/记忆），给建议与评分，迭代直至 **≥85 分；基准模型 ≥90 分**。
4. **输出**：非常详细的推导过程 + 思路讲解；公式 LaTeX 书写、**渲染必须正确**（md + pdf）；不会就参考 GitHub 高星项目（如 pandoc/KaTeX/MathJax/XeLaTeX 模板）。
