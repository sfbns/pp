## 一、需求：从个体到份额

原始效用 `U(ζ_i, p_j, x_j, ξ_j; θ)`。
(2.1) 选择集 `A_j = {ζ : U(ζ,p_j,x_j,ξ_j;θ) ≥ U(ζ,p_r,x_r,ξ_r;θ), r=0,…,J}`，`r=0` 是 outside good。
(2.2) `s_j = ∫_{ζ∈A_j} P_0(dζ)`；市场需求量 `M·s_j`。

**基准 logit（不够用）**
(2.3) `U = x_jβ − αp_j + ξ_j + ε_ij ≡ δ_j + ε_ij`，`δ_j = x_jβ − αp_j + ξ_j`。
(2.4) `s_j = ∫_ε Π_{q≠j} P(δ_j − δ_q + ε) P(dε)`。
致命缺陷：可加可分 + i.i.d. ε ⇒ **替代只取决于份额，与特征相似性无关**。份额相同的 Yugo 与 Mercedes 对任意第三辆车有相同交叉价格导数；份额相同的 Jaguar 与 Yugo 有相同自价格导数，因而（单产品厂商下）相同 markup。原文 p.847 用的就是这个例子。

**随机系数（BLP 的第一步）**
(2.5) `U = x_j β̄ − αp_j + ξ_j + Σ_k σ_k x_jk ν_ik + ε_ij`。
特征 k 对消费者 i 的边际效用变成 `β̄_k + σ_k ν_ik`。
分解：`δ_j = x_j β̄ − αp_j + ξ_j`，`μ_ij = Σ_k σ_k x_jk ν_ik + ε_ij`。

**汽车应用的实际规格（收入进效用）**
(2.6) `U = (y_i − p_j)^α G(x_j, ξ_j, ν_i) e^{ε(i,j)}`。
(2.7a) `u_ij = α log(y_i − p_j) + x_j β̄ + ξ_j + Σ_k σ_k x_jk ν_ik + ε_ij`
(2.7b) `u_i0 = α log(y_i) + ξ_0 + σ_0 ν_i0 + ε_i0`
消费者类型 `ν_i = (y_i, ν_i1, …, ν_iK)`——**收入本身是异质性的一部分**。
(6.14a/b) 最终经验式把收入写成对数正态：`α ln(e^{m_t+σ_y ν_iy} − p_jt) + x_jt β̄ + ξ_jt + Σ_k σ_k x_kjt ν_ik + ε_ijt`。

## 二、供给：多产品 Nash 定价（p.853–854 核过）

(3.1) `ln(mc_j) = w_j γ + ω_j`
(3.2) `Π_f = Σ_{j∈F_f} (p_j − mc_j) M s_j(p,x,ξ;θ)`
(3.3) `s_j + Σ_{r∈F_f} (p_r − mc_r) ∂s_r/∂p_j = 0`
(3.4) `Δ_jr = −∂s_r/∂p_j`（j、r 同厂）；`0`（否则）
向量 FOC（原文未编号）：`s − Δ[p − mc] = 0` ⇒ `p = mc + Δ^{-1}s`
(3.5) `b(p,x,ξ;θ) ≡ Δ^{-1}s`
(3.6) `ln(p − b(p,x,ξ;θ)) = wγ + ω`

> **实现警告**：`Δ` 的 (j,r) 元素是"j 的价格 FOC 行、r 的 margin 列"。若代码把 Jacobian 存成 `J_rj = ∂s_r/∂p_j`，必须写 `Δ = −(Jᵀ ⊙ H)`，H 是同厂指示矩阵。少转置一次就系统性错。
> 静态 Bertrand 成立需要：所有权已知、需求可微、内点定价、无未建模的库存/产能/经销商议价。原文脚注 12 明说多产品情形的均衡存在性不能由 Caplin–Nalebuff 直接推广，作者只做数值检查。

## 三、工具变量与识别（p.854 核过）

(4.1) `E[ξ_j|z] = E[ω_j|z] = 0`，`z_j = [x_j, w_j]`，`z = [z_1,…,z_J]`。
**价格和数量故意不进条件集**——它们本来就是内生结果。作者同时提醒：如果存在同时决定可观测与不可观测属性的"真实"模型，(4.1) 只在很特定的性质下成立。

(5.7) 最优工具思想：`H_j(z) = E[(∂ξ_j/∂θ, ∂ω_j/∂θ)' | z] T(z_j) = D_j(z) T(z_j)`——结构冲击对参数越敏感的观测点权重越高。
(5.8) 可操作基函数：对特征 `z_jk` 用三项——`z_jk`（自身）、`Σ_{r≠j, r∈F_f} z_rk`（同厂其他产品之和）、`Σ_{r∉F_f} z_rk`（竞争厂商之和）。这就是 "BLP instruments" 原型。直觉：竞争对手特征影响均衡价格，却不直接进入产品 j 的 `ξ_j`。

(5.1)(5.2) `E[(ξ_j,ω_j)'(ξ_j,ω_j)|z] = Ω(z_j)`，`T(z)'T(z) = Ω(z)^{-1}`
(5.3)(5.4) 总体/样本矩条件 `G_J(θ) = (1/J) Σ_j H_j(z) T(z_j) (ξ_j, ω_j)'`
(5.5) 实际最小化 `‖G_J(θ; s^n, P_ns)‖`——用的是样本份额 `s^n` 和 `ns` 次模拟得到的 `P_ns`
(5.6) 渐近方差 `(Γ'Γ)^{-1} Γ' (ΣV_i) Γ (Γ'Γ)^{-1}`，`V_1` 产品特征抽样、`V_2` 消费者抽样、`V_3` **模拟误差**。BLP 的标准误天然含模拟误差。
面板版本：同一车型跨年矩条件加总 `g_m(θ) = Σ_t [(f_mt(z)' ⊗ I_2)] (ξ_mt, ω_mt)'`，让标准误允许同车型跨期相关。

## 四、计算：反演、导数、模拟（p.865–867 核过）

(6.1) `u_ij = δ(x_j,p_j,ξ_j,θ_1) + μ(x_j,p_j,ν_i,θ_2) + ε_ij`
(6.2)–(6.5) logit 特例：`s_j = e^{δ_j}/(1+Σ e^{δ_j})`，`δ_j = ln s_j − ln s_0`，`ξ_j = ln s_j^n − ln s_0^n − x_jβ + αp_j`
(6.6) 条件份额 `f_j = exp(δ_j+μ_ij) / (1 + Σ_r exp(δ_r+μ_ir))`
(6.7) `s_j = ∫ f_j(ν_i, δ(x,p,ξ), p, x, θ) P_0(dν)` —— **无封闭解**，所以要数值反演

**(6.8) 收缩映射** `T(s,θ,P)[δ_j] = δ_j + ln(s_j) − ln[s_j(p,x,δ,P;θ)]`
迭代 `δ ← δ + ln(s^n) − ln[s(p,x,δ,P_ns;θ)]`。附录 I 证明其模小于 1、不动点唯一；证明用
`∂f_j/∂δ_j = 1 − (1/s_j)(∂s_j/∂δ_j)`、`∂f_j/∂δ_k = −(1/s_j)(∂s_j/∂δ_k)`，并写 `s_j(δ) = e^{δ_j} D_j(δ)`。

反演后 **`ξ_j(θ,s,P) = δ_j(θ,s,P) − x_j β`**（完整规格里价格通过 `α log(y_i−p_j)` 进非线性部分，因此这里不出现 `+αp_j`——这是初学者最常卡的一步）。

**(6.9a)** `∂s_j/∂p_j = ∫ f_j(1−f_j) [∂μ_ij/∂p_j] P_0(dν)`
**(6.9b)** `∂s_j/∂p_q = ∫ −f_j · f_q · [∂μ/∂p_q] P_0(dν)`

> ★★ **三处必须知道的坑**
> 1. **本机 walkthrough 第 31 条抄 (6.9b) 时漏了前置负号。** 漏掉就把交叉价格导数弄反，Δ 非对角元反号，markup 与 mc 全错。其他公式仅按逐式台账报告核验范围，不能概称均一致。**2026-10-07 已在全部 8 份副本中修正**（补负号、改写为 `∂μ_iq/∂p_q`、加更正说明，见 `D:\blp-structural-skill-config\VERIFICATION_LEDGER.md` G 节）；若遇到未改的旧副本（例如 0824 归档 zip 内），仍按本条处理。
> 2. **原文 (6.9b) 印的是 `f_j(ν, ξ, x, p, θ)`**，其他各处都是 `δ`——是原页笔误。
> 3. **原文 (6.9b) 印的是 `[∂μ_ij/∂p_q]`**，但 `μ_ij` 不含 `p_q`（q≠j），照抄得零。经济上应为 `[∂μ_iq/∂p_q]`。加负号后 `∂s_j/∂p_q = −∫ f_j f_q (∂u_iq/∂p_q) dP > 0`，替代品符号才对。

(6.10) 简单模拟器 `s_j(p,x,ξ,θ,P_ns) ≡ (1/ns) Σ_{i=1}^{ns} f_j(ν_i, δ, p, x, θ)`
(6.11) importance sampling 恒等式；(6.12) 最优抽样密度 `P*_hj(dv,θ) = [f_j(v,θ)p_0(v)dv]/s_j(θ,P_0)` —— 过度抽样"更可能买 j 的人"
不可直接用的三个理由（原文 p.866–867）：需要未知的 `s_j(θ,P_0)`；依赖 θ 而抽样必须固定；逐产品换抽样会破坏"份额加总为 1"，而收缩映射需要它。
可行做法：先用 (6.10) 得初始一致估计 `θ'`，再对 `ν ~ P_0` 以概率 `f̄(ν,θ') = Σ_j f_j(ν,θ')` 做 acceptance/rejection，所有份额共用同一组抽样，锚在 `s̄(θ) = 1 − s_0(θ) = Σ_j s_j`。
**(6.13)** `s_j[θ, P*_h(θ')_ns] = Σ_{i=1}^{ns} [s̄(θ',P_0)/f̄(ν_i,θ')] f_j(ν_i,θ)`，求和只对 accepted draws。

> ★ **(6.13) 的抽样计数必须先固定。** 原印刷式的求和与实现归一分开登记。本文默认固定 ns 个 accepted draws，它们来自条件密度 q(v)=fbar(v,theta0)p0(v)/sbar(theta0)。因此可实现的标准推导是 s_hat_j=(1/ns) sum_accepted [sbar(theta0)/fbar(v_i,theta0)] f_j(v_i,theta)，不得再除以 sbar。此前把固定 accepted 次数与固定 proposal 次数混同的实现说明撤回。
> 若另一算法固定 N 个 proposal draws，则 s_hat_j=(1/N) sum_{i=1}^N I_i f_j(v_i,theta)/fbar(v_i,theta0)，其中 I_i 为接受指示；accepted 个数随机，不能把 N 换成 accepted 个数。两式分别由条件密度换测度与逆概率加权推导；不要跨算法搬归一因子。四角色实测记录在 D:/codex/output/blp_bundle_20261007/package/03_BLP_foundation/formula_transaction，测试得到原抄式1.2、固定accepted修正式0.3、回滚1.2。
> 上述是实现用 standard-derived 修正，不伪装成原文逐字式。全体份额的有限模拟加总仍需数值检查，不因为理论期望加总正确就保证每个有限抽样精确加总。

## 五、七步操作流程

1. 定 `x_j`、`w_j`、`F_f`、市场与 outside；
2. 给定 `P_0`（收入分布用外部数据）；
3. 猜 `(α, σ)`；
4. 用 (6.8) 从观测份额反演 `δ`；
5. 由 `δ` 得 `ξ`，由 (6.9) 得需求导数 → (3.4) 得 `Δ` → (3.5) 得 markup → (3.1)(3.6) 得 `ω`；
6. 用 `ξ, ω` 和 (5.8) 工具构造 GMM 矩；
7. 更新参数直至矩条件趋零。

**五个关键词**：`δ_j` 平均效用 · `μ_ij` 个体偏离 · `ξ_j` 未观测质量（价格内生根源）· `Δ^{-1}s` markup · `δ ← δ + ln s^obs − ln s^model` 反演。
