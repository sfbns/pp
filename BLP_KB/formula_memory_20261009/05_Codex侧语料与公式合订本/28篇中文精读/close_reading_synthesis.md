# BLP 中文精读总记忆

## 这 28 篇共同在做什么
- 它们共同把“现实政策/市场问题”翻译成“产品差异化、替代关系、均衡反馈和福利比较”的结构问题。
- 真正值得记住的不是抽象的 BLP 名字，而是这套模型如何把价格、属性、异质性、供给反应和政策反事实接起来。

## 逐篇精读后最稳定的 BLP 记忆
- 标准骨架仍然是：消费者离散选择 -> 市场份额 -> 价格/属性内生性处理 -> 供给侧定价或市场结构 -> 反事实 / 福利。
- 变化主要出在三处：有的论文把供给侧做得很重，有的论文重点放在自然实验和需求估计，有的论文把网络效应、标签或进入问题接进来。

## 写作层面最值得记住的模式
- 好的 BLP 论文不会直接从方法讲起，而是先把现实政策争论讲成一个 reduced-form 不够用的问题。
- 制度背景和数据部分承担的是“为模型设定和识别开路”的功能，所以常常比纯方法论文更重。
- 收口一定要回到福利、政策比较或市场结构含义，否则结构模型的价值会显得不完整。
