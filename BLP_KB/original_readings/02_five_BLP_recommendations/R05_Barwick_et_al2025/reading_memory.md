# P01 精读卡｜Barwick, Kwon, Li & Zahur (2025)

**Drive Down the Cost: Learning by Doing and Government Policies in the Global EV Battery Industry**
NBER Working Paper 33378（2025-01，2025-08 修订）

> **对用户项目的定位：这是 P02 的姊妹篇，补上「补贴 → 采用 → 经验 → 成本下降 → 更多采用」这条动态反馈链。** 对用户而言最关键的一句话：**忽略这条反馈链会把政策效应低估到只剩 10–20%。**

---

## 一、四行脚手架

1. **基准视角研究 X 通过 Y**：EV 政策效应（X）通过**静态需求反应**（Y）研究（Springel 2019、Li et al. 2021、P02 自己也是）。
2. **Y 漏掉了 Z**：Z = **上游电池的干中学**。补贴提高销量 → 电池厂商积累经验 → 成本下降 → EV 更便宜 → 销量再升。**静态模型把这条回路整个切掉了。**
3. **什么设计隔离了 Z**：两项方法创新——(a) **在没有成本数据的情况下估计干中学**，靠「需求估计 → 下游加成 → 讨价还价模型 → 上游加成 → 残差即电池成本」这条链；(b) **用「供应商对下游 EV 补贴的暴露度」作为经验的工具变量**，并利用中国白名单政策作为外生冲击。
4. **结论如何改变**：**政策效应被放大数倍。** 补贴单独 +27.9% 销量；干中学单独 +95.4%；**二者合计 +204%，比之和大 65.5%。** 且**忽略干中学时福利收益与跨国溢出只剩 10–20%。**

## 二、★★ 方法论：没有成本数据如何估干中学

这是全篇最可复用的贡献。链条：

$$p_{jct}=\underbrace{mc^b_{jct}}_{\text{电池成本}}+\underbrace{mc^v_{jct}}_{\text{非电池成本}}+\underbrace{mk^b_{jct}}_{\text{电池加成}}+\underbrace{mk^v_{jct}}_{\text{EV 加成}}$$

**步骤**：
1. BLP 需求估计 ⇒ 弹性矩阵
2. 伯特兰 FOC（式 3）⇒ **下游加成 $mk^v$ 已知**
3. 纳什中的纳什讨价还价 FOC（式 4）⇒ **上游加成已知至差一个 $\lambda^b$**：
$$\boldsymbol{mk}^b=\frac{\lambda^b}{1-\lambda^b}[T^b\otimes S]^{-1}[T^v\otimes S]\,\boldsymbol{mk}^v$$
4. 残差 = 成本；把电池成本设为 $mc^b_{jct}=BK\cdot(\gamma_0E_{bt}^{\gamma_E}+\ldots+\eta t)$ 并用 GMM 联合估 $\gamma_E$ 与 $\lambda^b$

**★ 为什么 $\lambda^b$ 的不确定性不污染学习率（作者的关键论证）**：
> 「讨价还价权重影响**预测电池价格的水平**，而干中学由**电池价格相对累计经验的斜率**决定，后者在各设定间稳健。」

实测：$\lambda$ 从 0 到 0.5 变动，$\gamma_E$ 保持稳定；序贯 vs 同时、线性定价、组合讨价还价、动态 vs 静态，全部得到 −0.12 到 −0.18 之间的 $\gamma_E$。

### 经验的工具变量

$$E_{bt}=\sum_{s<t}\sum_c\sum_{j\in\mathcal I\{I_{bcs}=1\}}q_{jcs}$$

**IV 逻辑**：向补贴更慷慨国家销售电池的供应商积累经验更快。若存在干中学，其他条件相同时前者的电池成本会比后者下降更快。**外加中国白名单政策这一外生冲击。**

**稳健性**：重构 IV 排除白名单政策后 $\gamma_E=-0.147$（基准 −0.140）⇒ 结论不靠白名单。

## 四、★★ 与用户「工况切换」项目的映射

### 1. 「反馈回路」这一论证结构可直接移植

用户的问题：工况重标降低了标称续航 ⇒ 需求下降 ⇒ 销量下降 ⇒ **电池厂商经验积累变慢 ⇒ 成本下降变慢 ⇒ 价格更高 ⇒ 需求进一步下降**。
**本文提供了这条链每一环的可估参数**：学习率 9.2%、$\gamma_0$=958 美元/kWh、时间趋势 −28 美元/kWh/年、规模经济 −55 美元/kWh（产能翻倍）。

**⇒ 用户可以直接问：工况重标的静态需求效应会被这条回路放大多少倍？** 本文给出的放大倍数是 **204%/27.9% ≈ 7.3 倍**（补贴的情形）。

### 2. ★ 续航系数 1.019 是用户最直接可引用的需求参数

$\log(\text{range})$ 系数 **1.019**（完整模型），PHEV 交互 **−0.643** ⇒ **PHEV 的续航边际效用只有 BEV 的约 37%**。
**这为「工况重标对 BEV 的冲击远大于对 PHEV」提供了直接的结构式依据**，与 P11 的「续航效应对 PHEV 不显著」互为印证。

### 3. 「本地含量要求」框架可套用到中国双积分/白名单

本文已经把中国白名单政策完整建模并给出福利账。**用户若要分析工况重标对不同厂商的差别冲击（本质上也是一种「谁能拿到补贴」的规则变更），可以复用同一套网络形成模型 + 100 次模拟平均的做法。**

### 4. ★★ 「政策时点决定政策效力」这一发现

**白名单在 2016 年（电池成本 600–800 美元/kWh，学习曲线陡）推出 ⇒ 中国净收益；若推迟到 2021 年（成本 <200 美元/kWh，曲线已平）⇒ 中国净损失。**

**⇒ 对用户的直接含义**：工况重标（2021）恰好发生在中国 NEV 产业已渡过学习曲线陡峭期之后。**这意味着工况重标的动态放大效应应当小于早期补贴政策的放大效应——这是一个可检验且有理论依据的预测。**

### ★★ 三条可以直接写进用户论文的论点

1. **静态需求模型会把政策效应低估到只剩 10–20%。** 这是本文给出的最硬数字。**用户若只做简化式 DiD 或静态 BLP，必须明确声明自己估的是短期效应，且给出这个折扣倍数作为参照。**
2. **上游厂商只攫取其学习收益的 25–33%** ⇒ **干中学供给不足是补贴的正当性理由，独立于环境外部性。** 这条对中国 NEV 补贴的评价尤其重要：即便不算减排收益，补贴也可能改善福利。
3. **溢出的地理分布由供应网络重叠程度决定**：中国攫取自己补贴收益的 92.5%（因供应链本地化），欧洲只攫取 21%（因 EV 与电池双重进口）。**这为用户讨论「中国政策的国际外溢」提供了一个精确的量化框架。**

## 五、可引用的方法学警告

- **无法识别电池成本与车辆成本的水平**（表 3 注：「我们无法分别识别电池成本与车辆成本的水平，两者由固定效应捕捉」）。**图 5 的电池价格水平是用 2014 年 BNEF 指数校准的。**
- **跨国学习溢出无法可靠估计**：「全球经验与时间趋势高度相关，使全球干中学的可靠估计变得困难」。**这意味着 42% 这一干中学贡献是"内部 + 国内跨企业"的下界，不含跨国学习。**
- **跨化学体系的企业内学习估计不精确**，因为 >80% 的电池供应商只生产一种化学体系。
- **国内跨企业溢出 $\theta=0.034$ 不显著**（se 0.102）。作者如实写「该估计不精确，因为跨企业竞争对手经验变异有限」。**不得引用为「不存在溢出」。**
- **动态模型作了两个强简化**：(a) EV 生产者设定加成而非价格 ⇒ 完全传递；(b) 供应商不内部化今天价格对未来加成的影响。作者明说更丰富的模型「在我们的情境中不可处理」。
- **IRA 的完整政策模拟超出本文范围**，因为需要对电池与 EV 生产地点的变化建模。作者只作定性类比（类似「延迟白名单」）。
- **利润按总部所在国分配**（注 36），作者说明按生产国分配结果在定性上相似。
- 表 3 第 (4) 列的 **$\gamma_E$ 标准误 0.051**，$t\approx 2.7$——显著但不是压倒性的。第 (1) 列（−0.218，se 0.046）反而更显著，说明**加入控制变量降低了精度**。
