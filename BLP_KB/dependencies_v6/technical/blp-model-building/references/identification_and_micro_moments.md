# 识别、工具变量与微观矩

## 0. 一句话

本项目在未约束里程、信念与注意且无独立分离变化时，聚合份额**首先只识别复合响应**。这不是所有聚合BLP都无法区分参数的一般不可能定理；独立变化、已知先验或外部约束可能恢复条件识别，须检验矩秩。任何"我们识别出了短视/注意/信任/绿色光环"的说法，都要先证明有一条独立的外生变化或微观矩把它从复合项里分出来。

## 2. 工具变量三条硬规矩

1. **"BLP-style instrument" 这个名字不是证明。** 自身特征 / 同厂其他产品特征之和 / 竞争厂商特征之和（原文 (5.8)）只有在其外生或处理前预定的部分满足排除限制时才成立，且必须同时报弱工具稳健推断。
2. **价格IV的排除是条件于完整需求规格。** 不能把仍有未建模直接效用通道的政策楔子从需求式排除，再当作excluded price IV。若全部直接路径已正确入模且相应内生项被识别，并有可分离成本分量条件于included X满足E[Z^C ξ]=0、剩余价格相关性及联合矩秩，则原则上可条件有效；included X自身作included IV不同于excluded price IV。仅放入L、交叉拟合或强一阶段都不自动满足条件，本项目未据此认证有效价格IV。
3. **政策工具要按渠道拆开。** 燃耗标签、电耗标签、续航标签是三条不同的经济通道，不能先换算成同一任意单位再相减。每条各报相关性、排除理由、一阶段与秩。

政策楔子当作标签属性矩的条件（同时满足才行）：楔子仅由改革前配置或同配置双测构造 · assignment工具用预定资格而非内生采用；需求暴露另核实际展示及其内生性 · 模型已显式纳入认证/展示/感知 · 无遗漏的改革诱发工程升级、退出或广告重定位 · 在 carry-over / dual-tested / 硬件不变样本中有共同支持。

## 3. 微观矩：写法与优先级

**写法必须条件于真实抽样与可得选择集**，不能只写一个无条件总体期望。令 `S_nr=1` 表示个体 n 进入矩 r 的调查样本，`w_nr` 为调查/逆入样概率权重，`C_n` 为其实际可得集：

```
m_r^data  = Σ_n w_nr S_nr h_r(y_n, C_n) / Σ_n w_nr S_nr
m_r^model = Σ_n w_nr S_nr E_θ[h_r(Y_n,C_n) | X_n, C_n, S_nr=1] / Σ_n w_nr S_nr
g_{μ,r}   = m_r^data − m_r^model(θ)
```

产品层 IV 矩与微观矩**不能都写成 `Zξ`**。堆叠为 `g = [g_D ; g_micro]`，局部识别要求 `rank(E[∂g/∂θ']) = dim(θ)`；独立调查的抽样误差要进协方差矩阵。**把一条消费者调查答案复制到每个车型观测后当普通 IV 是错的。**

优先级（高→低）：
1. 第一选择—第二选择 / 考虑集 —— 直接约束替代与随机偏好
2. 年里程 × 油耗/电耗选择 —— 分开成本资本化与天然偏好
3. 长途/高速频率 × BEV 续航 —— 识别 `κ_i`
4. 家充条件、公共充电可达性 × BEV/PHEV
5. 标签识别、回忆、理解与可信度
6. 消费者预期油价/电价、持有期与折现
7. PHEV 电驱里程占比
8. 收入 × 价格、车型级别、动力系统
9. 搜索、点击、询价或广告曝光

**新车购买者样本的条件化：必须同时重权类型分布**：

令 F 为潜在消费者总体类型分布，P_iB=1-P_i0，s_B=∫P_iB dF。
购买者类型分布为 dF_B=P_iB dF/s_B；不能只把概率除 P_iB 却仍对总体 F 积分。

    Pr(first=j | B) = ∫[P_ij/P_iB] dF_B = s_j/s_B
    Pr(first=j, second=h | B)
      = ∫[P_ij/P_iB] P_ih^{-j,C} dF_B
      = [∫ P_ij P_ih^{-j,C} dF]/s_B

第二选择概率 P_ih^{-j,C} 必须在问卷实际允许的选择集删除j后计算；
outside只有问卷允许不买/保留原车时才在第二选择集合中。
调查/逆入样概率权重再恢复其明确目标总体；买家总体和潜在消费者总体不是一回事。
如从一开始只估计条件新车模型，则输入分布是购买者F_B，并且其条件份额系统
不恢复outside或总购车需求。以上联合概率先在同一类型计算再积分，不能乘边际积分。
可执行反例和正确重权见 scripts/micro_sampling_selftest.py；不要用加总为1代替检验类型选择偏差。

## 4. 方法边界（逐篇查完成证明，不能概称全部双遍精读）

- **Conlon & Gortmaker（PyBLP micro data）**：人口—选择矩主要识别**观测异质性 Π**；选择集变化、第二选择有助于Σ，但并非必要条件；标准聚合BLP也可依价格/特征/份额和有效矩的联合变化识别，须查局部秩及强度。第二选择等于观察"删除第一选择"的反事实集合。**不兼容的所谓 optimal moments 可能比不用微观数据更糟。**
- **Berry & Haile（micro data 非参数识别）**：丰富微观数据能帮识别替代，但"固定属性时的条件价格需求可识别" ≠ "改变属性/标签的因果效应可识别"。若标签、真实工程、认证优化与未观测质量共同内生，必须给它们**不同的**外生变化；不能全塞进 `ξ`，也不能拿一个全国统一 post dummy 当充分变异。
- **Miller & Weinberg（conduct 参数）**：`κ` 是企业间利润内化，**不是**认证测试、广告或披露选择。研究组织可迁移（reduced form 记事实 → 结构基准检验 → 反推 rival explanation → 外部材料约束 → 逐通道反事实），标签不可乱改名。

## 5. 结构—简约式一致性：什么才算验证

这条纪律两个 skill 共用，完整写法（两个模拟世界跑同一个简约式算子、样本分割、何时可并入联合 GMM、估计对象对齐）以 `structural-model-building/references/identification_and_claim_ladder.md` 第 5 节为准，这里只记 BLP 特有的三点：
- 标准 Berry 反演在同一市场内令 `s^model(δ̂,θ_2) = s^obs`，所以**把同样本反演得到的拟合销量再送进事件研究只是机械复制数据**；
- 模拟"有政策"与"无政策"两个世界时，`ξ` 固定为预定基准 `ξ^base`，硬件与产品集同时冻结，所有情景共用同一组随机抽样；
- 留出市场不用其销量反演 δ，而由处理前状态预测 `ξ^base`，这是 BLP 里最强的一种外部验证。
