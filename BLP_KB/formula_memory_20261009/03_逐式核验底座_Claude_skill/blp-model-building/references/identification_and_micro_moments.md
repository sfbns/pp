# 识别、工具变量与微观矩

## 0. 一句话

聚合份额**首先只识别复合响应**。任何"我们识别出了短视/注意/信任/绿色光环"的说法，都要先证明有一条独立的外生变化或微观矩把它从复合项里分出来。

## 1. 逐参数登记表（上表之前必须填满）

对每个非线性参数登记五栏：

| 栏 | 内容 |
|---|---|
| 变化来源 | 这个参数靠数据里哪一段变异动起来 |
| 排除变量 / 微观矩 | 具体哪条工具或哪个 moment |
| 有效支持 | 第一阶段强度、共同支持区间 |
| 主要 rival channel | 同一段变异还能被什么别的机制解释 |
| 局部秩 | 矩 Jacobian 对该参数方向是否有秩；profile objective 形状 |

模板（汽车/EV 场景，可直接改写）：

| 对象 | 主要变化来源 | 最关键额外矩 | 不满足时的安全表述 |
|---|---|---|---|
| `α_i` 价格敏感度 | 成本侧工具引起的成交价变化 | 收入 × 价格选择 | "条件价格弹性" |
| `γ_id` / `χ_id` 未来成本资本化 | 能源价格 × 工程能耗；机械标签楔子；里程 | 里程 / 持有期 / 价格预期 / 成本信念 | "有效未来成本权重"，不是短视 |
| `a_i` 标签注意 | 标签曝光、识别与搜索 | 回忆 / 点击 / 随机展示 | "与信任的合成反应" |
| `ϑ_i` 标签信任 | 官方值 / 广告值 / 真实道路三者之差 | 可信度调查或信息实验 | "与注意的乘积" |
| `κ_i` 续航不便 | 续航 × 长途频率 × 充电条件 | 行程分布右尾与家充数据 | "模型内 range WTP" |
| `τ_id` / `ψ_id` 天然动力偏好 | 选择集内替代 | 第二选择 / 考虑集 / 旧车动力 | "动力固定偏好，吸收多种遗漏" |
| `φ_i` 绿色光环 | 可见性或环境框架的外生变化 | 环境态度 × 可见性信号矩 | "与 EV 固定偏好混合" |
| `x^{endog}` 政策诱发工程属性 | 属性成本/技术供给工具 | 冻结属性的外部工程预测 | 只能"条件于观测 x 与产品集" |
| `ξ_jmt` | 产品/车型固定效应、市场时间效应、有效 IV | — | **不可被重新命名为机制** |

## 2. 工具变量三条硬规矩

1. **"BLP-style instrument" 这个名字不是证明。** 自身特征 / 同厂其他产品特征之和 / 竞争厂商特征之和（原文 (5.8)）只有在其外生或处理前预定的部分满足排除限制时才成立，且必须同时报弱工具稳健推断。
2. **直接改变消费者所见属性的政策楔子不能给价格做工具。** 它经由效用直接进需求，违反排除限制。它只适合形成**准实验外部矩**或敏感性样本。
3. **政策工具要按渠道拆开。** 燃耗标签、电耗标签、续航标签是三条不同的经济通道，不能先换算成同一任意单位再相减。每条各报相关性、排除理由、一阶段与秩。

政策楔子当作标签属性矩的条件（同时满足才行）：楔子仅由改革前配置或同配置双测构造 · 用法定资格而非企业选择的实际采用日 · 模型已显式纳入认证/展示/感知 · 无遗漏的改革诱发工程升级、退出或广告重定位 · 在 carry-over / dual-tested / 硬件不变样本中有共同支持。

## 3. 微观矩：写法与优先级

**写法必须条件于真实抽样与可得选择集**，不能只写一个无条件总体期望。令 `S_nr=1` 表示个体 n 进入矩 r 的调查样本，`w_nr` 为调查/逆入样概率权重，`C_n` 为其实际可得集：

```
m_r^data  = Σ_n w_nr S_nr h_r(y_n, C_n) / Σ_n w_nr S_nr
m_r^model = Σ_n w_nr S_nr E_θ[h_r(Y_n,C_n) | X_n, C_n, S_nr=1] / Σ_n w_nr S_nr
g_{μ,r}   = m_r^data − m_r^model(θ)
```

产品层 IV 矩与微观矩**不能都写成 `Zξ`**。堆叠为 `g = [g_D ; g_micro]`，局部识别要求 `rank(E[∂g/∂θ']) = dim(θ)`；独立调查的抽样误差要进协方差矩阵。**把一条消费者调查答案复制到每个车型观测后当普通 IV 是错的。**

优先级（高→低）：
1. 第一选择—第二选择 / 考虑集 —— 直接约束替代与随机偏好
2. 年里程 × 油耗/电耗选择 —— 分开成本资本化与天然偏好
3. 长途/高速频率 × BEV 续航 —— 识别 `κ_i`
4. 家充条件、公共充电可达性 × BEV/PHEV
5. 标签识别、回忆、理解与可信度
6. 消费者预期油价/电价、持有期与折现
7. PHEV 电驱里程占比
8. 收入 × 价格、车型级别、动力系统
9. 搜索、点击、询价或广告曝光

**新车购买者样本的条件化**（Xing–Leard–Li 型第一—第二选择模板）：
```
P_ij^sample(v) = P_ij(v)/(1−P_i0(v))   若样本 = 新车购买者
               = P_ij(v)               若样本 = 目标总体
P_ijh^sample   = ∫ P_ij^sample(v) · exp(V_ih)/Σ_{g∈C_i\{j}} exp(V_ig) dF(v)
```
`0 ∈ C_i` 仅当问卷允许"不再购买/保留原车"作为第二选择。新车购买者样本还须用调查权重恢复目标购买者总体，并记录问卷给出的可得集、缺失第二选择与抽样层。

## 4. 三条来自方法文献的边界（本机已双遍精读）

- **Conlon & Gortmaker（PyBLP micro data）**：人口—选择矩主要识别**观测异质性 Π**；缺 choice-set variation 时不能自动识别**未观测异质性 Σ**。第二选择等于观察"删除第一选择"的反事实集合。**不兼容的所谓 optimal moments 可能比不用微观数据更糟。**
- **Berry & Haile（micro data 非参数识别）**：丰富微观数据能帮识别替代，但"固定属性时的条件价格需求可识别" ≠ "改变属性/标签的因果效应可识别"。若标签、真实工程、认证优化与未观测质量共同内生，必须给它们**不同的**外生变化；不能全塞进 `ξ`，也不能拿一个全国统一 post dummy 当充分变异。
- **Miller & Weinberg（conduct 参数）**：`κ` 是企业间利润内化，**不是**认证测试、广告或披露选择。研究组织可迁移（reduced form 记事实 → 结构基准检验 → 反推 rival explanation → 外部材料约束 → 逐通道反事实），标签不可乱改名。

## 5. 结构—简约式一致性：什么才算验证

这条纪律两个 skill 共用，完整写法（两个模拟世界跑同一个简约式算子、样本分割、何时可并入联合 GMM、估计对象对齐）以 `structural-model-building/references/identification_and_claim_ladder.md` 第 5 节为准，这里只记 BLP 特有的三点：
- 标准 Berry 反演在同一市场内令 `s^model(δ̂,θ_2) = s^obs`，所以**把同样本反演得到的拟合销量再送进事件研究只是机械复制数据**；
- 模拟"有政策"与"无政策"两个世界时，`ξ` 固定为预定基准 `ξ^base`，硬件与产品集同时冻结，所有情景共用同一组随机抽样；
- 留出市场不用其销量反演 δ，而由处理前状态预测 `ξ^base`，这是 BLP 里最强的一种外部验证。
