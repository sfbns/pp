# 供给、反事实与福利

## 1. 多产品 Bertrand

利润 `Π_f = M Σ_{j∈J_f} (p_j^s − mc_j) s_j`，其中 `p^s` 是**厂商每辆净收**，`p^c` 是**消费者成交价**；有购置税、补贴、经销商优惠时两者必须分开：`p^c = p^f + τ^V − sub^V`。默认 `∂p^c/∂p^s = 1`；若经销商议价或补贴传导使该导数不为 1，需求导数要按链式法则调整，不能直接套 markup 公式。

所有权加权导数矩阵 `Δ_jk = −O_jk ∂s_k/∂p_j`，基准 `O_jk = 1{f(j)=f(k)}`。
FOC：`p − mc = Δ^{-1} s`。基线反推：`m̂c = p^obs − Δ̂(p^obs)^{-1} ŝ(p^obs)`。

- 合资分利、交叉持股或共同控制者定价时，按公司治理预先构造 `O_jk ∈ [0,1]` 并做 conduct 敏感性。**"自主/合资"这个产品标签本身不等于利润内部化权重。**
- 求解器：`p^r = mc^r + η(p^r)`，`η = Δ^{-1}s`；或 Morrow–Skerlos 的 `ζ` 固定点（数值上常更稳）。**没有"一般必然收敛或均衡唯一"的定理；小残差也不证明利润最大或 proper equilibrium。**
- 供给块上线前必过：观测份额回放 · 边际成本反演 · FOC 残差 · 观测价格回放 · SOC / 利润 Hessian · 多初值 · `p ≥ mc` · 价格有限 · 独立模拟抽样稳定性 · 多均衡检查。跨情景用 common random numbers 降差分噪声，再用独立抽样检验绝对误差。

**这个模块只能区分"固定价格需求效应"与"maintained Bertrand 下的价格反馈"。它不识别广告、认证操纵、工程属性或产品进入。**

## 2. 属性/披露选择只能是有条件扩展

`Π_f = M Σ_r [p_r − mc_r(a)] s_r(p,a,g) − K_f(a) − H_f(g)`，`C_f^{reg} ≤ 0` 为监管约束。
价格已最优时：
```
0 = M Σ_r [(p_r−mc_r) ∂s_r/∂a_j − s_r ∂mc_r/∂a_j] − ∂K_f/∂a_j − ρ_f ∂C_f^{reg}/∂a_j
0 = M Σ_r (p_r−mc_r) ∂s_r/∂g_j − ∂H_f/∂g_j − ρ_f ∂C_f^{reg}/∂g_j
```
**只有价格 FOC 不能识别 `a_j` 与 `g_j`。** 缺工程成本、真实道路测试、广告原文、认证约束或准实验时，企业部分只能停在"把实际认证、双口径展示、极值突出、价格、退出和工程属性当结果变量"，结论写成"与战略性显著化一致"，不是"已识别企业造假"。

## 3. 反事实：先登记状态向量

每个场景先写清 `Ω = (L, T, p, x, J, ξ, mc, Network; χ, a, ϑ, b, κ, φ, ψ)` 里**改什么、固定什么**。所有场景共用同一组随机抽样；`ξ` 固定为预定基准质量，**不能因为关掉某通道就让 ξ 重新吸收政策**。

推荐阶梯：
1. 实际基准（记录实际认证、展示、硬件、可售集与价格）
2. 纯标签取消 / 只切某一侧标签（固定真实性能、硬件、产品集、价格）
3. 正确信念（移除标签—真实楔子）
4. 会计等权资本化（逐抽样令 `γ_id = α_i`，**不是**令某个平均系数比为 1）
5. 无绿色光环 / 无续航误认（分别开关）
6. 在以上任一需求状态下允许多产品企业重新定价
7. 工程 / 广告 / 进入退出响应——只有相应成本与状态转移被额外识别后才启用

**固定价格反事实不得调用供给求解器**；重新定价基线必须能回放观测价格。

## 4. Shapley 分解：能做什么、不能做什么

通道非线性交互，逐一关闭有顺序依赖，用 Shapley：
```
Φ_k = Σ_{A ⊆ K\{k}} [|A|!(K−|A|−1)!/K!] · [v(A∪{k}) − v(A)]
```
验证 `Σ_k Φ_k = v(K) − v(∅)`。`v(A)` 是"只有集合 A 处于 on 状态"的完整状态下的结果差，所有派生信念、成本、不便与内生价格都要重算。

**边界**：Shapley 只是给定已估模型与场景不变量下的**顺序无关会计分摊**，不是 DID 中介效应。**对没有独立识别的通道（例如复合项 `γ·a·ϑ`），绝不能算成三个"因果贡献率"。** 只靠归一化分开的机制，只报 benchmark 与顺序敏感性范围。

## 5. 福利：四条轨道，不能混

### (a) 决策 surplus（准线性 + 条件 EV1）
每个抽样内 `α_i > 0` 共享、误差尺度跨状态相同：
```
G_i^{D,r} = log Σ_{j∈J^r∪{0}} exp(V_ij^{D,r})
ΔCS = M Σ_i w_i (G_i^{D,1} − G_i^{D,0})/α_i,   Σ_i w_i = 1
```
Euler 常数在差分中抵消。Small–Rosen 的 required compensation 取相反符号。
**必须逐抽样除以自己的 `α_i` 再聚合，不能用平均 `ᾱ` 除平均 logsum。** `M` 必须是份额分母里的购买机会，不是居民存量。

### (b) nested / RCNL 的 GEV surplus
```
J_ig^r = log Σ_{j∈g∩J^r} exp(V_ij^{D,r}/λ_g),   λ_g = 1 − ρ_g
G_i^{NL,r} = log[ exp(V_i0^{D,r}) + Σ_g exp(λ_g J_ig^r) ]
```
`λ_g`、误差尺度、效用归一化必须跨状态共同。**不能把普通 MNL logsum 填进 NL/RCNL 福利表。**
nested logit 的 dissimilarity 映射：`λ^{NL} = 1 − ρ`，同巢误差精确相关 `= 1 − (λ^{NL})² = 2ρ − ρ²`，**不是** `ρ`。

### (c) 有收入效应时的精确 CV/EV
逐个体根求：`V_i^{q,1}(y_i + CV_i^{req}) = V_i^{q,0}(y_i)`；`V_i^{q,1}(y_i) = V_i^{q,0}(y_i − EV_i^{req})`。
若 `η_i, ε_i` 是跨状态稳定品味，去掉外层期望、对同一抽样根求；若 `ε` 只是选择前临时冲击，用期望最大效用。转移矩阵、CV/EV 与经验福利必须用一致的 shock timing / coupling。
**多价格改变不能拆成若干单价格改变后沿固定收入顺序积分 Marshallian 概率。**

### (d) 决策效用 vs 规范经验效用
信念有误或 `χ ≠ 1` 时，选择时的 logsum **不是**规范性体验福利。做法：实际选择仍由决策效用决定 `j_i^{D,r} = argmax U_ij^{D,r}`；再用真实道路指标、实现里程、真实不便构造规范效用 `U^{W}`，**并单独规定货币边际效用 `λ_i^W`**——沿用决策价格系数 `α_i^D` 是一个规范假设，不是估计结果。
规范口径预注册三条并行：`preference-respecting`（保留稳定内在偏好，只把事实性信念换成真实状态）· `experienced-use`（只计真实使用结果与稳定体验）· `informed-choice`（让消费者获知真实值后重新最优化再算 CV/EV）。
**三者回答不同问题，不能挑最有利的当唯一主福利，也不能把 `ΔCS^{decision}` 与 `ΔEW^{realized}` 相加。**

### (e) 质量/标签福利的识别边界（Bhattacharya）
一般质量或标签福利**不由结构选择概率非参数点识别**。每个相关反事实分三层报告：① parametric BLP 点估计；② 弱可分 / Condition-S 敏感性；③ bounds 或明确写"不能点识别"。
删除产品的平均福利还依赖把选择概率积分到价格趋于无穷的尾部支持；有限数据支持通常只给下界，RC logit 的完整尾部来自函数形式外推。必须并列观测支持截断界、尾部截断敏感性，并说明新产品评价是前瞻还是回溯。选择集扩张使 logsum 不下降只是单调性测试，**不是尾部识别测试**。

### (f) 闭合社会账户
```
SW = EW^W + Π_vehicle + Π_energy + Rev_fiscal − C_public − D_external − C_gaming,real
```
规则：`EW` 用消费者**实际支付**价与零售能源支出 · `Π_vehicle` 用企业**净收**价并扣真实成本 · `Π_energy` 用不含能源税的净收入并扣真实资源成本 · `Rev_fiscal` 是税费/积分/罚款净额减补贴 · 转移项必须在消费者、企业与财政间**配对** · 信息错误造成的错配已反映在经验福利里，不能再扣一次。
**任一部门（能源、固定成本、财政流）缺失，就分列各项，不输出一个伪精确的 `ΔSW`。**

## 6. "消费者转向哪里"的三层测度

1. **动力/组份额差**（最稳健）：`S_d^r = Σ_{j:d(j)=d} s_j^r`；纯标签固定价格效应 `ΔS_d^{label,FP}`。结果表必须同时列 ICE/HEV/PHEV/BEV **和 outside**——BEV 增量不必等于 ICE 减量。
2. **局部 diversion**：`D_{j→k} = −(∂s_k/∂p_j)/(∂s_j/∂p_j)`。**组间 diversion 不能对产品 diversion 简单平均**，要先规定源组产品受到的共同局部冲击权重 `h_j`，分母是该冲击造成的源组总份额损失，并把 outside 作为目的类别之一；对 `h_j=1`、销量权重、等比例价格冲击做敏感性。
3. **反事实个体转移矩阵**：共同稳定抽样下 `P̂_{d→d'}`，每行和须为 1，且必须含 outside（`d(0)=O`）。**聚合份额只识别前后边际分布，不识别跨状态联合分布**，所以只能叫 `common-shock simulated coupling`，并对共同抽样、独立重抽与 Fréchet 可行界做敏感性。B1/B3 必须跨状态共用同一组 nested-GEV nest shock 与产品 shock，不能改用 i.i.d. EV1 配对。
