- **包2（Z2，冯笑.zip）8 篇新文献**：F01–F08（另一份与 C02 重复），标签/信息披露、贝叶斯劝说、量化贸易、双积分 DID、行为实验。

## 3. 每张卡的结构
- 通用卡（C/F）：引用信息 → 一句话结论 → 背景 → 文献综述（具体方向与代表文献）→ 数据 → 方法/模型 → 结果（含数字）→ 贡献 → 政策与局限 → 可复用要点。
- 结构模型卡（A/M）：引用信息 → 一句话结论 → 问题与动机 → 文献综述 → 数据 → **6. 结构模型如何构建（6.1 需求、6.2 供给、6.3 均衡/其他模块、6.4 识别、6.5 估计算法、6.6 反事实与福利）** → 估计结果 → 反事实结果 → 贡献 → 局限 → 公式校正与笔误 → 可复用要点与关联文献。

## 4. 标记约定（导入时请保留）
- **[D]**：卡片作者由原文数字推算/换算得到，原文未直接印出。
- **待核 / †待核**：文字层缺失或错乱、无法对照原页确认的数字或公式，引用前须查原 PDF。
- **据文字层重建**：该篇没有公式校正段，公式由机器抽取文字重建。
- **原文笔误/前后不一**：卡片第 11 节（或相应小节）逐条列出；照抄原文前先看。
- 公式以包3 的【公式校正】段为准（A00 汇总）；包3 的 15 份校正覆盖核心模型式，其余公式为文字层重建。

## 5. 核对方法
- 每张卡片都用 `tools/numcheck.py` 把卡中数字与原文全文逐一比对。对不上的数字逐个确认过，属于以下几类：标 [D] 的推算值、单位换算或四舍五入、节号或元数据，或已标"待核"。
- 表格文字层错乱的，对照了原页图；包1/包2 用 pypdfium2 渲染，包3 用包内"核对页图"。仍无法确认的标"待核"。
- 包3 卡片由子代理逐篇全文精读写成，主会话逐篇复核。主要复核结论：
  - A01 BLP 表 IV 参数：与 M01 表 8 转载的原文估计逐一比对，一致。
  - A22 的 txt 实为 2022 年 7 月工作论文版（题目不同），已在卡片和 A00 中注明。
  - A23 作者为 Barwick、Li、Xia。
