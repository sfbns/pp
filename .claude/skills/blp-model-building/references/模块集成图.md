# 模块集成图：从问题到方程，而非从论文到清单

`B` 是共享需求核；`H/C/I/R` 改消费者块；`S/A/N/D/L` 改供给、均衡或时序；`W` 是与前面共同编译的评价块。节点证据见来源账本同名 `node_id`。这里的跨论文组装是 `[D:本协议构造]`，不是任何一篇论文已经估计过的系统。

## 1. 问题路由与最小模型

| 输入经济问题 | 首选最小模块 | 何时升级 | 必须拒绝的跨越 |
|---|---|---|---|
| 价格弹性、近邻替代、产品删除 | B；有总体类型分布则 H | 第二选择/人口调查可改善 H；仅有组内相关证据才加 R | 不因“复杂”加动态；已购者调查不自动恢复总需求 |
| 谁买什么、政策分配效应 | B+H | 类型×属性矩、第二选择、外部总体重权；W | 人口—选择矩不自动识别所有随机系数；样本数不是支持 |
| 生命周期成本估值 | B+C；里程为 H 的类型 | 给定先验/真实值后可加 I；W 区分评价口径 | 不自由同时估计里程尺度、折现、资本化和信念后命名短视 |
| 信息/标签改变但实体属性不变 | B+I；若货币化用 C | 独立先验、展示、成本变异支持分离参数才升级 H/I | 纯重标不推出信念必变；非 BLP 自然实验不是 BLP 估计证明 |
| 税补贴转嫁、兼并 | B+S；明确实付价/净收价 | 价格—收入曲率重要且有支持才加收入版 H；R 需替代证据 | 不能从单产品常数成本的曲率界推出一般多产品上限 |
| 厂商重新设计质量/合规属性 | B+S+A | 技术前沿、属性成本、约束与影子价格信息到位 | 只有价格 FOC 不识别设计；测量方程不当技术前沿 |
| 给定网络的需求 | B+N_cond | 网络变异满足排除；反事实只改给定 N | 不强制网络进入；不拿条件系数称乘数 |
| 补贴—网络进入—需求反馈 | B+S+N_eq，必要时 A | 网络成本/进入与市场闭合已识别 | 不把偏导放进反馈后的定价 FOC；不假定唯一均衡 |
| 等待购买、替换或二手市场 | D 包含 B 的当期选择核 | 持有状态/转移/预期数据到位，明确动态均衡 | 多期静态 BLP 不是 DDC；购买等待不由静态 outside 常数识别 |
| 累计产量降低成本、创新 | L+当期 B/S；区别学习与研发 | 上下游交易/经验 IV 支持学习；研发需额外投入与知识转移 | R05 学习模型不识别任意专利/研发函数；静态属性优化不是创新 |

## 2. 构造依赖图

```text
问题/目标对象
  ↓
市场M、可得集C_i、outside、效用尺度、时序/信息集
  ↓
B: δ+μ+ε → P_i(C_i) → s → 反演 → ξ → IV/GMM
  ├─ H: F(z,ν) + 入样机制 → 人口/第二选择微观矩
  ├─ C: 单位/持有期/预期 → 主观广义成本
  ├─ I: 信号+先验 → 后验/决策成本（先验不是后验）
  └─ R: GEV相关核 → 概率、反演阻尼、surplus同步替换
  ↓
S: 实付价/净收价 + 所有权 + 行为 → 价格FOC → mc/供给矩
  ├─ A: 工程前沿+属性成本+约束 → 属性FOC/KKT
  ├─ N_eq: 网络进入/供给 → 反馈后的总导数与联合均衡
  └─ L: 上游议价/成本与累计经验转移 → 路径
D: 当期核 + 持有/等待/转移/预期 → Bellman选择价值
  ↓
W: 同一选择核/同一冲击时序 → 钱度量 → 账户 → 支持/外推界
```

所有消费者模块先生成同一个 `V_ijt` 与 `P_ijt`，不能各自单独估弹性后相加。所有供给模块以同一需求导数和相同税补贴账户为输入。D 不是在静态 `V` 上机械加一个折现率；它替换消费者的选择价值和数据似然/份额算子。L 不必要求消费者也动态，但需明确谁前瞻、谁短视以及当期定价均衡。

## 3. 模块接口、有效前提、失败与检验

| 模块/文献节点 | 接口及正确前提 | 可观测量与识别变异 | 典型失败/数值检验及退回 |
|---|---|---|---|
| B / BLP95, CG20 | 加性 ξ、明确 outside 与位置/尺度；可微静态选择核 | 产品—市场份额/价格/属性、潜在购买机会；有效成本/特征/竞争环境变异 | s0≤0、零份额、弱秩；查反演残差、有限差分导数、分布退化。无可靠 M 则只作条件购买模型，不报总需求 |
| H / PETRIN, GMY, CGMICRO, XLL | F 是目标总体，调查统计量与模型复制同一入样/可得集；删集乘积分解只用于条件独立EV1排序 | 人口—选择、第一第二选择；跨市场人口及选择集变异 | 买家条件概率用错 F、相关矩当独立、RCNL误用logit排序；重权/联合排序/分子分母测试、排除可疑矩 Wald。失败则只保留可兼容矩 |
| C / GRV, LU | G 为货币现值，实际/名义一致；使用强度尺度受外部约束 | 工程成本、能源价、里程/持有期/预期；同配置或其它有效成本变异 | γ×里程×现值因子共线；比例逐类型算、单位/尺度不变测试。无分离则报有效成本权重 |
| I / RS21, GHVB, BELIEF | 说明标签、先验、后验与真值；认识权重仅是模型参数 | 信号/先验/真实性能；独立变化或外部限制使联合矩满秩 | γ、ω 与未知先验互相补偿；尺度化秩/profile与表示不变性。失败降为复合响应/敏感性；不得命名心理机制 |
| R / GV14, GALICHON | 同一树的 GEV 概率与surplus；$\lambda=1-\rho$，合法参数序 | 巢内/巢间替代及有效工具；第二选择可作模型比较 | ρ非行为权重、巢内份额内生；$\rho\to0$回RC、完整log-share差阻尼、两类残差。失败回RC或合法候选树 |
| 收入版 H / KT25 | $f(y-p)$ 单调、预算可行；inside/outside同一 f | 收入与价格分布、税额等有效价格变异；形状限制 | 曲率靠外推、$p=y$不连续；预算边界/导数/精确CV根。失败回受限 f 或支持内界，不能偷用logsum/α |
| S / BLP95, CG20, MW17 | 所有权/定价行动/内点/链式税楔子明确；conduct另识别 | 价格、企业归属、成本移动；conduct需regime及成本协同比较 | 异常mc、错转置、库存/产能遗漏；FOC、SOC、观测价格回放、多起点与抽样。失败只报需求或行为敏感性 |
| A / BKL24, ALE, REYNAERT | 真实技术与成本约束已知/估计；阈值KKT不是光滑FOC | 属性/工程前沿、技术成本、规制阈值；属性独立IV | 价格FOC冒充属性识别、遗漏固定成本；互补松弛、偏离利润、价格—属性联合回放。失败冻结属性 |
| N / NETWORK, REMMY | N_cond允许给定网络；N_eq另给进入及均衡选择 | 网络规模/供给成本/保有量/进入；双侧排除与闭合 | 反馈导数与偏导混用、多均衡隐去；反馈Jacobian、不同初值/分支、N反馈归零回静态。失败只做条件N情景 |
| D / DYNAMIC | 持有、等待、购买效用时序及状态转移明示，贴现受约束 | 持有/更替、价格预期、状态转移；动态排除与支持 | δ/流量效用/主观转移共线；Bellman残差、转移行和、β=0退化（仅当等待终值也匹配）。缺源/数据则设计框架，不称动态估计 |
| L / LEARNING | 经验转移、上下游成本/议价与前瞻行为明示 | 供应链/价格/累计经验/政策暴露；排除时间趋势及共同技术 | 学习=研发、水平分解不识别、照搬放大倍数；冻结经验路径回当期模型、零学习弹性、价格/成本回放。无条件则固定成本路径 |
| W / WELFARE, SR, BHATT | 福利必须选准线性/GEV/收入效应及决策/体验规范口径 | 可得集与同状态价格/质量、α_i或CV根、财政/外部损害 | 平均α、换核logsum、按真值重选冒充既有选择体验；同状态零差、补偿根/账户守恒、删除尾部支持。缺账户分列不报总福利 |

## 4. 兼容性规则：每次组合都要重新算的接口

1. **H×C×I**：联合类型可相关，不默认独立。先验/里程/折现的尺度不受约束时，γ与ω可能同秩。人口/第二选择约束的是分选与替代，不自动为信念提供排除。必须报告联合（非逐参数单独）矩 Jacobian 的尺度化奇异值及 profile；没过就合并参数。
2. **R×W**：估计用RCNL，福利也用逐类型GEV surplus；λ与EV1尺度跨状态共同。若另有收入效应，GEV只给期望最大效用，货币补偿仍逐类型根求，不除常数α。
3. **收入效应×S**：$J_{jk}=\partial s_j/\partial p_k$ 一般不对称，$\Delta_{jk}=-H_{jk}J_{kj}$；对称准线性特例不能掩盖索引错。实付价非线性映射还需 $\partial p^c/\partial p^s$。
4. **A×N_eq**：属性改变可改变网络进入，需求导数是合适时序下的总导数；网络冻结与网络响应是不同均衡概念，不拼用各论文FOC。先明确网络进入发生在定价/设计前后、厂商是否内化。
5. **S×D/L**：静态价格FOC只有在当期价格不改变被内化的未来价值或明确短视时才成立；否则加 continuation-value 导数并估其状态。动态学习的供应商议价不能用下游所有权矩阵代替。
6. **I×W**：保留决策选择，另以真实结果评价体验；“完全信息重新选择”是另一个反事实。不自动以决策α作规范货币边际效用。
7. **属性IV×完整系统**：论文中的补贴、轴距、供应商工具是该文维持假设，不是通用许可证。加入新的直接效用/网络/质量通道后，重审每条排除与联合秩。
8. **静态×动态**：可以把已识别静态需求当动态模型的当期核；必须重定义outside、购买机会、持有状态和冲击耦合。不能把“多个年份”或“现值成本”当动态购买行为证据。
9. **H×R的第二选择**：标准RC-logit在给定类型的EV1结构下才有D03删集概率乘积。RCNL/nested的同冲击排序须用正确联合排序概率；实际问卷若是重新选择或新冲击则另定义。核对软件micro对象与调查，未认证联合排序实现时保留人口矩/停用排序矩，不能把接口名称当兼容证明。

## 5. 四条示范组合（构造示范，不是已跑模型）

- **人口分配 + 产品删除**：B → H（总体收入矩/第二选择）→ W。最小版用有效aggregate变异识别RC；升级版加入正确买家抽样的micro。删除产品在原F下重算概率；若只知购买者F_B，则结果是条件新车替代，不声称不购买流向。
- **成本估值 + 信息**：B+C；先固定外部里程和持有/折现，估复合成本权重。升级为 I 仅在已知先验或独立信号变化提供新增秩时；同一总体调查的成本信念和第二选择共用协方差。行为命名和体验福利另列限制。
- **税补贴 + 内生质量 + 网络**：B+S；最小版固定A/N。独立识别A后解价格—属性，独立识别网络侧且时序相容后才加入N_eq。用 $F_p\,dp/dz+F_a\,da/dz+F_N\,dN/dz+F_z=0$ 明示联立反馈，不把三种局部响应相加（本协议[D]的隐函数接口，不是文献原式）。
- **属性设计 + 学习**：当期 B+S+A；中期只允许外部已给成本路径；升级L要识别经验—成本与上游议价/动态激励，再联立路径。R05卡仅支持具体学习接口，不能据它宣布任意研发模型可识别或搬用政策放大倍数。
