## 2. 需求侧改造（D 组）

### D1 Petrin (2002) JPE：用"汇总的消费者信息"补识别
- **问题**：只有市场份额时，能识别替代模式的选择集变化太少，消费者第一与第二选择数据又稀少且多为私有（工作论文版 p.8）。
- **改了哪个原语**：P3。算法骨架不动，只在 BLP 的份额矩与 `E[ξ|X,W]=E[ω|X,W]=0` 之外加 11 个微观矩。
- **机制写法**：价格以 `α_i ln(y_i − p_j)` 进入，`α_i` 按三个收入等分组取不同值（p.10）；家庭规模与面包车、旅行车口味交互，让家庭车之间的替代有可观测来源（p.11）。
- **所需理论**：偏好异质性与分选。某类车的买家平均特征（家庭规模、户主年龄、收入组购车概率）是"谁在买什么"的总体矩，约束的是 Π。
- **识别与数据**：CEX 1987–1992 约 3 万户中 2660 笔新车购买；产品 1981–1993 年 916 个车型（p.14）。11 个矩为三个收入组购车概率、四类家庭车买家平均家庭规模、四类买家户主年龄 30–60 岁的概率（p.15–16）。
- **估计**：份额矩照 Berry (1994) 反演（p.16）；供给侧多产品 Bertrand-Nash，反解一阶条件得边际成本，`ln mc_j = W_jτ + ω_j`（p.12）。
- **结论与福利**：有限的额外信息就能显著压缩 i.i.d. 误差的作用，使收入边际效用、弹性与新产品（minivan）福利更合理（p.10）。
- **三标记**：齐（p.16 反演，p.12 FOC 与 mc）。
- **来源**：`D:\blp-lit-recommend-20261002\BLP经典改造与近期改造文献推荐_20261002.md` 第三节；本地 PDF 文字层坏，只能看 `D:\blp-lit-recommend-20261002\pageimg\petrin_p05–p19.png`，页码为工作论文印刷页。

### D2 Grieco, Murry & Yurukoglu (2024) QJE：人口矩 + 第二选择矩 + 外部选项分解
- **问题**：1980–2018 年产品与技术一直在变，加价率不再是可比的效率指标，外部选项的吸引力也在变。
- **改了哪个原语**：P3、P5、P12。
- **机制写法**：随机系数 logit，消费者收入、家庭规模、农村身份随年份演变；用 Pakes 等 (1993) 的分解，借持续在售产品把逐年需求冲击拆成"不可观测质量提升"与"外部选项价值变化"。
- **所需理论**：消费者剩余的零点依赖外部选项；若外部选项本身变好，跨年 CS 比较会被污染。第二选择等于观察"删掉第一选择后的反事实选择集"，直接约束替代。
- **识别与数据**：CEX（1980–2005，年均约 1014 个观测）与 MRI（1992–2018，年均约 2005 个）的人口—购车联系矩（如按收入五分位匹配所购车平均价格）；MaritzCX 1991、1999、2005、2015 年第二选择调查，匹配首选与次选车属性的相关系数（作者版 p.7、13、16）；价格工具为美国与产地国实际汇率；市场规模为住户数除以 2.5。
- **估计**：BLP GMM 堆叠微观矩；供给侧静态 Nash-Bertrand 反推加价，并以垄断、合谋等行为假设做稳健性。
- **结论**：加价率中位数由 1980 年 0.325 降到 2018 年 0.185，消费者在剩余中的份额上升，福利增长主要来自质量与生产技术进步；换成普通 logit，福利增幅约为本模型的 5 倍，差距来自对产品数量扩张的估值（作者版 p.26）。
- **三标记**：齐。**来源**：同上报告第四节（一）；全文 `D:\auto-demand-lit-2026-09\fulltext\J03.txt`（2023-03 作者版，页码与期刊版不同）；卡 `D:\auto-demand-lit-2026-09\cards\J03.json`。证据层级为全文定位加模型段人工阅读。

### D3 Hong, Kim & Verboven (2026 WP)：每公里使用成本 × 个人里程
- **问题**：减排补贴该给最清洁的纯电，还是给替代燃油车更多的混动。
- **改了哪个原语**：P2、P3。
- **机制写法**：每公里使用成本既带随机系数、又与个人年里程交互（作者版表 4，p.22）。开得多的人更看重低使用成本的纯电与混动；日均里程由 20–40 km 升到 60–80 km 时纯电份额由 2.22% 翻倍到 4.44%（p.23）。
- **所需理论**：作者第 5–9 页的理论框架。中间技术若能更多地把消费者从高排放技术拉走，其减排效果可以超过最清洁技术，关键在"被转移的排放"而不是单车排放节约。
- **识别与数据**：韩国 2012–2023 年产品—省—年数据；个人年里程数据与 2018、2023 年两轮第二选择调查作微观矩（p.3、17），沿 Conlon–Gortmaker 与 Grieco 等的做法。
- **估计**：RC logit（Berry 1994；BLP 1995）+ 微观矩 GMM；供给侧式 (13) `p^G = mc − (Ω∘∇s_p)^{-1}s` 在观测价格处反推边际成本，再求补贴情景的均衡价格与转嫁矩阵（p.24）。生命周期排放按个人里程计算。
- **结论**：把纯电补贴预算平移为统一混动补贴，总排放多减 47%；纯电补贴要胜出，发电碳强度需再降约 45%。
- **与工况重标的关系**（本项目推论）：工况改变消费者看到的使用成本，谁对它敏感取决于里程，这是五篇里离项目最近的一篇。
- **来源**：报告第四节（二）；`D:\auto-demand-lit-2026-09\fulltext\W07.txt`（2026-09 版，结论可能修改）；作者顺序按标题页，SSRN 元数据顺序不同。

### D4 Grigolon, Reynaert & Verboven (2018) AEJ:EP：把未来燃油成本写进价格括号
- **问题**：车主在多大程度上低估未来燃油成本，这对燃油税与产品税的比较意味着什么。
- **改了哪个原语**：P2、P3。
- **机制写法** `[O·卡]`（本机原文 md，式 (1)(4)(7)）：
  `u_ijk = x_jk β_i^x − α_i (p_jk + γ G_ijk) + ξ_jk + ε_ijk`，`G_ijk = ρ β_i^m e_jk g_k`；
  `β_i^m` 是个人年里程，`e_jk` 油耗，`g_k` 油价，`ρ` 由利率与年限算出的现值因子。估计式把 `α_i` 设成 `α/y_t`。
- **所需理论**：跨期权衡与现值资本化（Hausman 1979 的隐含贴现率传统）。`γ = 1` 表示每 1 欧元贴现燃油成本与 1 欧元车价等价。里程异质性带来分选：高里程者偏好省油车，不建模会把分选误读成低估。
- **识别**：`γρ` 与里程尺度不可分，**用英国全国出行调查的经验里程分布钉住尺度**（并把购车条件分布映射成无条件分布）。车型固定效应下，参数来自同一车型不同发动机版本之间的价格与燃油成本差异；燃油成本方差的 77% 来自同燃料内发动机差异，13% 来自汽油与柴油之差，油价时序变化几乎不贡献。主要识别假设是除价格外的产品特征（含油耗、油价）与残差质量均值独立。
- **估计**：BLP 收缩映射反演；直接估 "fuel cost parameter" `αγρ`，再除以 α 与给定的 ρ 得 γ。
- **结论**：每 1 欧元贴现燃油节省只换来 0.91 欧元车价支付意愿，低估温和；考虑里程异质性后燃油税相对产品税更有优势。
- **来源**：`D:\数据说明段_支撑文献md包_20260930\17_Grigolon_Reynaert_Verboven_2018_AEJEP_燃油成本估值与税收政策_原文.md` 第 I、III 节；28 篇语料卡 `D:\codex\economics_theory_agent_complete_gpt55_xhigh\kb\04_literature\structural_papers\04-consumer-valuation-of-fuel-costs-and-tax-policy-evidence-from-the-european-car-market.md`。

### D5 Lu (2023)：生命周期燃油成本 + 里程分布
- **机制写法** `[O·卡]`：`u_ivt = α_i x_v + β(p_v + γ G_ivt) + ζ_vt + ε_ivt`，`G = ρ m_it E[g_t]/mpg_v`。估计只识别 `γρ`，给定 `r = 6%`、`S = 35` 才报告 γ。
- **识别与估计**：车型间 MPG、价格差异与市场内里程分布；BLP 反演；BLP 风格属性作价格工具。
- **结论**：带经验里程分布的 IV RC logit 得 `γ = 1.03`（SE 0.47），点估计接近一但精度不足以区分温和低估与完全资本化。
- **边界**：inside goods 只有汽油车，混动与纯电合并为"outside"，**不是标准 BLP 的不购买外部选项**；油价为共同常数，MPG 可能与未观测质量相关；里程分布进模拟类型却没有"哪类里程者买哪类车"的微观矩。

### D6 Kaneko & Toyama (2025) JIE：把收入效应非参数化
- **问题**：参数化收入效应先验地锁死需求曲率，曲率又决定补贴转嫁与兼并涨价。
- **改了哪个原语**：P1、P5。
- **机制写法**：`V_ijt = f(y_it − p_jt) + β'X_jt + θ_f + θ_t + ξ_jt + ε_ijt`，外部选项 `f(y_it)`；份额里显式带预算约束指示 `1{y_it ≥ p_jt}`；f 只要求弱递增，用 Bernstein 多项式筛近似并施加单调约束 `π_k ≤ π_{k+1}`，实证用其倒数形式使需求在 `p = y` 处连续。
- **所需理论**：Weyl & Fabinger (2013)：对称寡头或垄断下，转嫁率小于 1 当且仅当需求对数凹；准线性 logit 是对数凹的，**即使不用准线性，给收入效应指定函数形式也会限制曲率与转嫁**（原文 p.196；09-20 台账记 P10 公式页已视觉核验，p.196 与脚注 37 本轮按原文文字层核对）。脚注 37：`∂²s_j/∂p_j² = ∫{s_ij(1−s_ij)(1−2s_ij)[f′]² + s_ij(1−s_ij) f″} dG`，**价格线性进入的参数化随机系数模型里 f″ ≡ 0**。
- **识别**：税额工具（同厂其他车型与竞争者车型的税额之和，剔除依赖价格的取得税）；假设厂商在产品推出前不观测 ξ（引 Eizenberg 2014）。传统 BLP 工具在日本数据上一阶段很弱。
- **估计**：嵌套不动点，内层收缩映射求 δ；外层只对筛系数做非线性搜索，β 线性集中；预算约束使 Berry 的线性回归形式不再成立。基准不含随机系数（只有 8 个市场年）。
- **结论**：环保车补贴转嫁率 1.194（线性 logit 0.991，被 1 封顶）；丰田—本田假想兼并涨价 2.68%/7.30%（线性 logit 0.59%/1.37%）；半参数模型的 CV 分布双峰。
- **★ 边界**：讲的是**价格—收入曲率**，不是续航价值曲率；"标准 BLP 表达不了续航曲率"已被 09-20 台账撤回。
- **来源**：`D:\fuel-econ-lit-2026\cards\P10_Kaneko_Toyama_2025_精读卡.md`；原文 `D:\fuel-econ-lit-2026\raw_text\P10_Kaneko2024_JIE.txt`（p.196 约第 562 行，脚注 37 约第 2034 行）。

### D7 Grigolon & Verboven (2014) REStat：RCNL，以及巢参数到底是什么
- **机制写法** `[O·卡]`：`u_ijt = δ_jt + x_jt Σ ν_i + Σ_g d_jgt ζ_igt + (1−ρ) ε_ijt`，嵌套 logit、RC、RCNL 都是它的特例；两层嵌套须 `0 ≤ ρ₂ ≤ ρ₁ < 1`。
- **所需理论**：GEV 与 nested logit 的随机效用表示。Galichon (2022) 证明 nested logit 等于同巢共享一个正稳定分布公共因子的混合 logit，同巢相关为 `1 − λ²`，巢参数是相关结构的限制，**不是**行为参数。
- **识别与估计**：反演 + GMM；价格内生，工具含同厂、竞争者特征之和以及巢内、子巢内特征之和；巢内份额是内生均衡结果，不是自己的工具；每市场 500 个 Halton 抽样；**强嵌套时标准迭代失去单调性，要对完整 log-share 差值乘 (1−ρ) 阻尼**。
- **结论**：欧洲汽车数据同时拒绝纯 NL 与纯 RC；马力与油耗的随机系数对环境政策尤其要紧；兼并价格效应在三种模型间较稳，市场界定结论不稳。
- **来源**：`D:\codex\output\blp_driving_cycle_structural_research_20260824\iteration5_welfare_nested_pricing_20260825\03_pass1_cards\grigolon_verboven_pass1.md` 与同目录 `galichon_pass1.md`。

### D8 Durrmeyer (2022) EJ：feebate、地方人口微观矩与分配
- **机制写法** `[O·卡]`：市镇层偏好是人口特征的确定函数 `β_m = β̄ + Σ^X d_m'`，`α_m = ᾱ + d_m σ_p`；feebate 写进消费者净价 `p̃_j + λ_j`，于是在净价表达里 fee 像边际成本上升、rebate 像下降，市场力使目录价与利润率调整，转嫁不必为一。
- **识别**：地方销售构造两组微观矩，匹配各车型买家平均人口特征，以及人口特征与产品特征的协方差（每市镇平均只有 19 辆新车，直接用市镇份额会有大量零份额）。
- **估计**：全国份额反演均值效用，地方微观矩约束异质性；多产品 Bertrand 反推成本，再解"没有 feebate"的反事实均衡。
- **边界**：只建模**纯金钱渠道**，产品属性固定，信息、显著性与偏好变化被主动排除，所以结果不是政策总效应。
- **来源**：`D:\codex\output\blp_driving_cycle_structural_research_20260824\iteration3_new_papers_20260824\03_pass1_cards\durrmeyer_2022_french_feebate_pass1_card.md` 第 4–5 节。

## 3. 供给侧与市场结构改造（S、N 组）

### S1 Barwick, Kwon & Li (2024 NBER WP)：企业同时选价格、电池与车重
- **问题**：中国按续航分档的新能源车补贴怎样同时改变销量、产品设计与加价。
- **改了哪个原语**：P9、P11、P1。
- **所需理论**（原文第 2 节）：单产品垄断下若需求写成 `Q(P − B(x))`，价格与属性可分，私人最优属性满足 `B_k − C_k = 0`，社会最优要加外部性 `φ e_k`，因此除数量扭曲外还有属性扭曲；两部制补贴 `T + t z(x)` 中固定部分管数量、强度部分管设计；预算有限时最优属性落在 iso-私人剩余与 iso-社会剩余曲线切点构成的 contract curve 上；多产品寡头下产品特定补贴要拉平最后一元的边际社会剩余。实证模型放松了"WTP 同质"的假设。

## 6. 从这些文献归纳的八种机制构建模式

| 型 | 怎么搭 | 需要的理论 | 识别靠什么 | 估计改哪里 | 例 |
|---|---|---|---|---|---|
| A 货币化的成本项 | 把机制写成带单位的货币项放进价格括号：`−α_i(p + γG)` | 跨期选择与现值、油价预期（鞅假设）、里程分选 | 与 ξ 正交的运营成本变化（同车型不同发动机、跨国油价）；外部里程分布钉尺度 | μ 里多一个随抽样里程变化的项；报告比值，逐抽样算 | D4、D5、D3、B2 |
| B 类型交互 + 微观矩 | 让偏好随可观测类型变化，用总体统计量约束 | 偏好异质性与分选 | 人口—选择矩、第二选择、里程矩 | 外层 GMM 堆叠微观矩，模型对应量用同一组抽样并复制调查抽样机制 | D1、D2、D3、D8 |
| C 换函数形式 | 放松价格—收入形状或误差相关结构 | 曲率与转嫁（Weyl–Fabinger）；GEV 表示 | 税额或差异化工具；巢内份额要工具 | 筛 GMM + 形状约束；RCNL 阻尼反演 | D6、D7 |
| D 第二个企业选择写成 FOC | 拉格朗日函数里加属性与规制约束，影子价格进 FOC | 多属性质量选择（Spence 扭曲）、规制下的成本最小化 | 属性成本移动项；外部工程前沿；未合谋企业的 FOC | 供给侧加属性 FOC 联合 GMM；反事实解价格—属性联合均衡 | S1、S2、S3、S4 |
| E 外部性联立 | 效用里放网络规模，另写进入方程 | 间接网络效应、双边市场、多重均衡 | 网络规模的 Bartik 工具；保有量的移动项 | 联立方程估计；反事实在需求与进入间迭代，检查多重均衡 | N1、S2 |
| F 行为假设参数化 | 所有权矩阵换成 `Ω(κ)` | conduct 与利润内化 | regime shift + 联盟外比较组 | 供给矩 × 时期指标 | S5 |
| G 自然实验 + 结构翻译 | 先用"只有标签变"的冲击识别价格或份额响应，再用 logit 恒等式翻译成估值参数 | 供给弹性与 WTP 的关系、均值之比偏误 | 冲击意外、供给冻结、同硬件 | 直接把 ΔG 放进回归，不事后相除；供给有弹性时报界 | B1 |
| H 信念或注意进效用 | 效用里用主观值替代官方值，`PVOC_hat = ω PVOC(L) + (1−ω) PVOC(B)` | 贝叶斯更新、不注意（左位数）、信任 | 必须有调查、信息实验或随机展示，否则只识别复合权重 | 加信念矩或外部校准；无数据时 ω 只能叫复合权重 | 项目 [P]、B3 |

**共同纪律**：每种模式都是"先点名机制落在哪个原语，再给它一条独立的变化或一组微观矩"。没有独立变化，就只报复合项（`structural-model-building` 的 claim ladder 第 2 节）。

## 7. 改造后，估计算法每一环要改什么

| 改造 | 内层（份额反演） | 外层（矩与目标函数） | 额外方程 | 数值注意 |
|---|---|---|---|---|
| 微观矩 | 不变 | 堆叠 `g_micro = f(v̄) − f(v(θ))`；同一调查拆成"所有买家"与"某类买家"时用分子分母 micro parts，不能当两个独立数据集 | 无 | 两组矩按估计协方差加权，不能随意同权；兼容性用 Wald 检验 |
| 第二选择 | 不变 | 模型对应量 `s_ijk = s_ij · s_ik(−j)`，要在删掉 j 的选择集上重算概率 | 无 | 问卷是否允许"不买"作为第二选择决定 0 是否在集合里 |
| 非参数收入效应 | 收缩映射仍可用，但预算约束指示让 logit 线性回归形式失效 | 对筛系数做非线性搜索，形状约束是必需的 | 无 | 用倒数 Bernstein 保证需求在 `p = y` 连续，否则均衡求解不稳 |
| RCNL | 阻尼 `δ ← δ + (1−ρ)[log S − log s]`，ρ→1 时极慢 | ρ 并入 θ₂ | 无 | 两层须 `ρ₂ ≤ ρ₁`；同时检查份额残差与不动点残差 |
| 生命周期成本 | μ 里加随里程抽样变化的成本项 | 识别 `αγρ`，再除以 α 与给定 ρ | 无 | ρ 是校准量；比值逐抽样算 |
| 内生属性 | 不变 | 加属性 FOC 残差的条件矩 | 技术前沿另估；影子价格 λ 的处理须预先说明 | 反事实同时解价格与属性，数百产品联立 |
| 网络效应 | 网络规模进 δ 或 μ | 网络规模本身要工具 | 进入方程 | 反事实迭代需求与进入，报多重均衡检查 |
| conduct κ | 不变 | 供给矩与时期指标交互 | 无 | κ 的解释边界见 S5 |
| 合规属性合谋 | 不变 | 由非合谋者属性 FOC 估罚金函数 | 合谋参与约束给界 | 得到的是界，不是点估计 |

通用步骤（Conlon & Gortmaker 2020 的 NFXP 与最佳实践）见 `estimation_algorithm_and_code.md` 第 0 节。

## 8. 对工况重标项目最可迁移的组合（按 2026-09-20 纠错台账口径）

- **需求**：D3 型里程异质性 + D4/D5 型生命周期成本 + 项目的信念算子与标签权重 ω + 由出行缺口推出的续航不便 `−κ_i E[(D_i − R)_+]` + D2/D3 型第二选择微观矩；outside 由潜在购车市场规模定义。X1 说明第二选择矩对替代结构有价值，但**不许可预先把动力类型固定成正确的 nest**，应比较 RC、候选嵌套树与外部 diversion 的拟合。
- **供给**：先冻结属性、只允许重新定价；S1/S2 作为有数据门槛的中期扩展；S3/S4 是企业测试与披露策略的结构模板，只有道路实测与披露数据到位后才启用，其余时候只能写成理论 rival。
- **识别**：B1 是同硬件重标的设计母本；连续预定暴露识别的是**每单位暴露的差异化响应**，不会凭空生成未处理对照。
- **福利**：决策福利与体验福利分开；助推福利看扭曲方差（B3）；插混外部性与燃油车差距很小（P08 表 2，见记忆 `reference_phev_externality_no_advantage.md`）。
- 项目细节与数据门槛见 `project_china_driving_cycle.md`。

## 9. 已撤回或不可移植的用法（09-20 台账第 2 节，一律不要再写）

1. 连续标签楔子可以替代对照组 → 撤回；
2. P18（Bai 等）的产品内跨维度 FE 能解决本项目没有对照组 → 撤回，P18 的结果是同一车型的多个质量维度，销量是单一标量；
3. "政策换算规则 × 改革前属性"构造的工具能挡住工程适配 → 降级为候选工具；
4. 残值渠道改变需求斜率或价格系数 → 通常错误，残值进入广义价格 `p + PVOC − PVResale`，改变的是平均效用；
5. P14 证明认知不足是效应可见的前提 → 撤回；
6. 标签效应必须随时间衰减 → 降级为可检验但不唯一的预测；
7. P10 证明标准 BLP 表达不了续航曲率 → 撤回；
8. P11 的 5.58%、P12 的 200 km、0.65 换算因子可以移植 → 撤回或禁止移植；
9. NEDC→CLTC 必然使续航下降、PHEV 为 −17.3% → 撤回为待数据核验事实；
10. φ<1 或标签反应小就等于短视 → 禁止直接命名；
11. ICE 销量下降等于 BEV 销量增加 → 撤回；
12. P18 旧工作论文数字 0.087 与 3.8%–19.5% → 由 AER 2025 正式版的 0.098 与 8.3% 替代。
