## 3. answer

### 3.1 用户规划是一个研究，不是四个松散新题目

Xmind/HTML 的总题为“官方能源测度重标、消费者有限注意与汽车技术选择”。三问依次为：

1. **采纳**：BEV/PHEV 的购买、潜在市场份额和支付意愿；分别考虑自身重标、ICE 重标及联合改革。
2. **替代与匹配**：从高油耗 ICE、节能 ICE、HEV、PHEV、BEV、outside 中的谁转向谁，结合第一/第二选择与 diversion；地区真实使用条件参与异质性，而非一律当噪声。
3. **政策与福利**：真实场景信息、总成本展示、可信口碑、补贴及组合；先固定价格，再允许价格反馈；体验福利、真实能源/排放、财政与分配分别核算。

**不能预设**新标签更准、短视降低、必然电动化或信息福利必为正。严格同硬件双工况比较与实际展示时间是对象校正；工程参数变化、净价变化、准入/牌照与充电约束不能偷放进“认知变化”。政策的产业远期信号、电网市场和全行业创新不属于当前主线。

### 3.2 经济对象：先分信念，再分资本化，最后才谈偏好

用户 PDF 的清晰贡献是分开 `eL`（标签）、`e0`（购买前先验均值）、`eRhat`（购买前后验）、`eRbar`（历史车主报告）和 `e*`（与个体条件相匹配的真实能耗）。这五个对象不能互相替代。

- GRV 的核心式为 `u = xβ − α(p + γG) + ξ + ε`；`G` 是有单位的预期折现生命周期燃料成本；`γ` 是条件于使用里程、燃料价格预期、寿命和贴现基准的未来成本估值。PDF7–8/期刊199–200明确，`γρ` 与里程尺度不能凭份额自由分开。其完整 RC 规格 `γ=0.91, SE=0.18`，不能拒绝充分估值，**不是“证明所有消费者短视”**（PDF19/22，期刊211/214）。[GRV 原刊](https://www.aeaweb.org/articles?id=10.1257/pol.20160078)
- R&S 把真值 `x`、信息 `m`、差距 `g=x−m` 与感知 `x_tilde=x−(1−α)g` 分开。其 `α` 是看穿操纵程度的简约场景参数，不是本项目贝叶斯 `κ`。作者尝试估计认知但未获统计上有意义结果，随后将 `α∈[0,1]` 用于反事实。因此它支持**偏好不变、感知属性改变**的机制基准，不能说已实证识别消费者先验或学习率（PDF18/29，期刊389/400）。[R&S 原刊](https://www.aeaweb.org/articles?id=10.1257/pol.20190019)
- 于是“真实油耗—标记油耗差距”首先是测量映射/信息楔子；“消费者预期—条件真值差距”才是相关信念误差；`γ` 是未来成本资本化/注意楔子；`θ` 是内在特征偏好。一个需求斜率可混合这些对象，**不等于所有人油耗边际效用同时发生偏好变化**。
- 用户 PDF 的 `Ω` 定义是同一人同一车的后验效用减先验效用，不是新的自由系数；在效用中放后验项后不得再加一遍 Ω。`κ` 变化不等于 `γ` 变化；工程旧工况预测不等于消费者先验。PDF18–20 的斜率比识别只在共同参数、已知 K、`e0=eL` 等限制下成立，不是一般异质模型的识别定理。

### 3.3 品牌口碑：能观测的指标，不是自动学习/信任证据

BLP1995 的 PDF11–12/期刊850–851把 style/prestige/reputation/past experience 作为研究者难量化的需求特征示例，而不是生产者和消费者都不知道的属性。测得口碑后，应放入可观测部分，剩余 `ξ` 是**未解释的剩余质量**；不能说评分就是 ξ。[BLP 原文](https://doi.org/10.2307/2171802)

品牌 ZIP 的合理工作口径：购买前可见、非能源维度的品牌均分，可以是可感知质量/声誉的代理；“品牌”应按消费者识别的品牌而非当然按最终母集团。均分的效用系数只叫有效代理反应，不能无条件叫纯品牌资产、信任、学习或短视效应。应保留：

- 均分/正负评价（valence）、数量（可能信息精度/流行度）、离散度和曝光/可信度四者分开；评分总和＝条数×均分，不能当纯正面口碑。
- 全部品牌×时间共同评分的均值效应会被品牌×时间固定效应吸收；随机斜率并不能恢复被吸收的均值系数。
- 车主报告不是购买前潜在消费者的无选择样本；缺失不能填零；固定篮子指数也不等于当时实际看见的评分。
- 贝叶斯信号需说明量表映射和噪声，1–5 星不是天然物理质量。后验属性与“先验＋增量 Ω”只能二选一，不能总评分、细分后验与 Ω 重复计效用。
- 改革后口碑即使滞后也可能是内生中介；lag/leave-one-out/跨城市/跨平台不是自动有效 IV。总标签效应、固定口碑的直接效应与口碑反馈反事实不是一个 estimand。

## 4. mechanism_chain

**偏好固定的信念路径（条件性）**：监管测量映射改变 → 同硬件可见数字/解释内容改变 → 购买前能耗/续航后验改变（需要实际曝光与信任）→ 预期终身私人总成本/可用性改变 → 个体选择概率与技术间 diversion 改变 → 企业价格反应 → 体验福利与实际能源/排放。

**资本化路径（另需证据）**：同一总成本信息的注意/计算成本改变 → 未来成本资本化 γ 改变 → 同一后验成本的效用权重改变 → 选择与价格反应。不能从销量反应直接宣称这条路径而排除信念路径。

**口碑反馈路径（不能假装已外生）**：重标/销售构成/真实体验改变 → 发布者与发布内容改变 → 可见口碑数量/均值/不确定性改变 → 其他潜在消费者信念改变。每个箭头都需时间顺序、曝光与选择校正；总政策效应与中介效应分开。

## 5. predictions

这些是待检验的条件性预测，不是已识别结果或无条件符号。

- 固定偏好、γ、硬件和价格，只有后验能耗上升的车型，其成本通道效用弱降；整体 BEV/PHEV/ICE 份额仍取决于各技术相对更新、outside、充电约束与价格反馈。
- 信念路径应伴随购买前同一物理量后验的可测变化；纯呈现路径可在数值内容、后验与 γ 不变时改变选择，但应有独立设计来识别。
- 资本化路径应改变对**相同预期成本流**的权重，而不只是报告的 L/100km；高里程者成本变化更大只能证明成本暴露异质性，不能单独证明更少短视。
- 同标签改革反应若只给出 `αγKκ` 一类复合系数，不能逐个给这些心理参数命名。选择/价格拟合不证明机制识别。
- 口碑若只是均分代理，其数量与均值应分别入模；所谓“更多评论提升评价”若由总分定义机械产生，不能当行为机制。
