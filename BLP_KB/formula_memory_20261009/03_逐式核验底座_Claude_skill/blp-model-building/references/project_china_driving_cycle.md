## 4. 观测差的四项分解

`Δ log L^k_jt = W^{k,mech} + A^{k,eng} + A^{k,test/disclosure} + u^{k,meas}`

## 5. 三条结构工具（不能合成一个 Post）

```
Z^{F,cycle}_jt = Elig^{F,legal}_jt · [log L̃^{F,new}_j(X_{j,pre}) − log L^{F,old}_j]
Z^{E,cycle}_jt = Elig^{E,legal}_jt · [log L̃^{E,new}_j(X_{j,pre}) − log L^{E,old}_j]
Z^{R,cycle}_jt = Elig^{R,legal}_jt · [log L̃^{R,new}_j(X_{j,pre}) − log L^{R,old}_j]
```
矩条件 `E[Z̃^{cycle} · ξ(θ_0)] = 0`，`Z̃ = Z − E[Z|C]`，`C` 含预注册固定效应与同期政策控制。
排除限制要求改革**不**经由工程、配置、边际成本、价格、广告、进入退出或未观测质量直接影响需求。
**用法定资格，不用企业选择的实际采用日。** 排除不成立时，BLP 仍可拟合需求，但固定供给标签反事实只能叫 `maintained structural counterfactual`，不等于政策简约式总效应。

## 6. 决策效用（iter5 冻结版）

```
u^D_ijmt = x'_jmt β_i + ψ_{i,d(j)} + φ_i·GreenSignal_jmt + ξ_jmt
           − α_i p_jmt − γ_{i,d(j)} Ĝ_ijmt − κ^B_i R̂I^B_ijmt·1{d(j)=B} + ε_ijmt
```
- 信念：`log T̂^k = log T^{k,prior} + a^k_it ϑ^k_id (log L^k − log T^{k,prior}) + b^k_id`
- 主观全寿命能源成本：`Ĝ = Σ_ℓ [q_ijℓ M_{i,t+ℓ} / (100(1+r_i)^ℓ)] · [(1−ζ)π^F T̂^F + ζ π^E T̂^E]`，ICE/HEV `ζ=0`、BEV `ζ=1`、PHEV `0<ζ<1`
- 续航不便：`R̂I = E_{D~F^D_i}[ℓ_0(D, T̂^R, C_imt)]`，尺度固定、效用里估 `κ_i ≥ 0`。**三种写法（外置 κ / 内置个体效用损失 / 严格货币化乘 α）只能选一种，不能重复计价。** PHEV 若启用要用独立的 `RI^P, κ^P`。
- 资本化 `χ_id = γ_id / α_i`，无量纲；**逐消费者算**，`E[γ/α] ≠ E[γ]/E[α]`。主表叫 capitalization ratio，`χ<1` 只能写"与短视一致"。
- 绿色光环 `φ_i·GreenSignal` 是**非货币**效用，与信念偏差 `b^E_iB, b^R_iB` 是两件事；`φ>0` 不蕴含消费者高估 EV 经济性。若只有 EV dummy，`φ` 与 `ψ_{i,B}` 不可分。
- 正值系数用相关对数正态块，不用事后截断。

## 7. 只靠标签能识别什么

```
∂u^D/∂log L^k = −[γ_{i,d} ∂Ĝ/∂log T̂^k + κ_{i,d} ∂R̂I/∂log T̂^k] · a^k_it ϑ^k_{i,d} + φ_i ∂GreenSignal/∂log L^k
```
聚合份额首先只约束 `γ·a·ϑ`、`κ·a·ϑ` 与绿色导数之和。要分开必须有：现期能源价格 × 工程能耗 · 同硬件双工况/桥接值 · 外部里程/持有期/折现分布 · 第一/第二选择与信念调查 · 标签识别/信任实验。
只有产品销量、价格和标签时，安全表述是 `χ_d^composite`：**"在所设信念与里程校准下的资本化比率"**。
PHEV 特有链式项：`∂Ĝ/∂log T̂^R = Σ_ℓ [q M /(100(1+r)^ℓ)] (∂ζ/∂log T̂^R)(π^E T̂^E − π^F T̂^F)` —— BEV 固定 `ζ=1` 时为零，PHEV 不能漏。

## 8. 主表顺序与不可删的诊断

主表：工况工具一阶段 → **B0 受限结构 Logit** → **B2 micro BLP** → 同一改革反事实的份额/销量/价格拟合 → 机制、供给、福利。
不可删：三条通道各自的一阶段 · 政策前需求趋势 · 伪适用日期 · 伪工况楔子 · 同期补贴/双积分/牌照/车型换代 · 有效政策冲击数 · 弱工具与 generated-regressor 推断。
**2021 日历切换不是 RD**；fuzzy RD 只有找到不可操纵的审批批次/生产日期阈值并验证一阶段跳跃后，才作局部补充。
推断至少在车型/认证配置层聚类；同一认证配置在城市和月份的复制行**不是独立样本**；有效政策 cohort 少时用 shock-level / randomization inference。
总效应回归**不得控制处理后变量**（实际认证、展示与广告、改革后成交价、发动机/电池/软件/整备质量变化、产品退出、改革诱发的充电网络响应）。

## 15. 09-20 纠错台账后的研究架构

**文献四层**（台账 02 第 1 节）：P15 Gillingham–Houde–van Benthem (2021) 是"可见官方评级变化 → 未来燃料成本资本化"的直接母本；P08 Allcott 等提供 ICE/HEV/PHEV/BEV/outside 替代、第二选择矩与均衡重新定价的做法（但其需求是校准的嵌套 logit，不是 BLP）；P02 Barwick–Kwon–Li 提供价格与属性同时内生的多产品供给；P03 Xia & Zhang (2025)、P18 Bai 等 (2025 AER 正式版) 与 Hörner & Samuelson (2026 AER) 提供产品组合、工程足迹与"可见指标诱发企业选择"的竞争解释。

**基准研究问题**（台账 MEMORY_MAP 第 3 节）：工况改革如何改变消费者看到的政府认证标签，该信息变化如何通过预期使用成本、有效续航和残值信念，重新配置 ICE、HEV、PHEV、BEV 与 outside 的选择；同时企业是否通过价格、工程属性、产品组合、测试或披露作出响应。"短视"只是待区分的复合机制之一。

**机制链**（台账 02 第 3 节）：短期 `实际黄色标签启用 → 标签接触 → {注意、理解、信任} → 主观使用成本、有效续航、残值信念 → 五类选择`；中期 `需求移动 → 价格与折扣 → 进入退出、真实工程适配、测试披露与广告 → 新标签与产品集`；长期链只在冲击持续且状态变量可识别时启用。

**可写进论文的六条假说与证伪**（台账 02 第 4 节）：H1 标签表示不变性基准（完全理解且可无损换算时，纯口径重表示不改变需求；标签实际展示前销量已变是对信息渠道的强证伪信号）；H2 ICE/HEV 标签油耗效应随预期里程、持有期、油价增强；H3 续航不便来自出行缺口 `A_i(R) = E[(D_i − R)_+]`；H4 替代方向不预设；H5 供给反应与信息效应按快慢分层（快慢本身不是充分证据）；H6 标签改善大于硬件与道路表现改善、且广告集中强调可见指标时，与测试或披露操纵一致。

**信念增广 micro-BLP**（台账 03 式 (4)(5)）`[P]`：
`u_ijmt = x'β_i + ζ_{i,g(j)} + ξ_jmt − α_i p_jmt − α_i φ_{i,g(j)} PVOC_hat_ijmt + α_i PVResale_hat_ijmt − κ_i A_i(R_hat_ijmt, N_mt) + ε_ijmt`；
广义价格 `GC = p + φ PVOC_hat − PVResale_hat`，**残值是广义价格的加性项，不自动改变 α**。PHEV 的运营成本必须允许电驱份额与两套能耗同时进入（台账 03 式 (7)）。估计配方见 `estimation_algorithm_and_code.md` 第 7 节。

**实际标签事件研究与 BLP 的分工**（台账 03 第 9–10 节）：目标 `ATT(g,t) = E[Y_jt(g) − Y_jt(∞) | G_j = g]`，G_j 是消费者实际看到新黄色标签的首月；若 G_j 由企业按改款、库存、预期需求选择，因果解释需要条件独立、无预期、风险集可比与 cohort 条件平行趋势，否则只能叫"实际采用事件关联"。连续预定暴露的事件研究系数 `π_e` 识别每单位预定暴露的差异化响应，**不是平均标签效应，也没有自动生成未处理对照**。事件研究先作外部验证；若要写成最小距离矩 `g^RF(Θ) = β̂^RF − β^model(Θ)`，必须联合处理同一数据产生的协方差，不能一边用同一销量估 BLP、一边把事件研究系数当独立外部矩。

**Go/No-Go**（台账 04）：车型事件研究要有实际标签首月、严格配置谱系、标签切换不与改款或补贴资格机械绑定、cohort 预趋势可接受、not-yet-treated 有共同支持、结果是终端销量而非产量；macro-BLP 至少要月度真实可售选择集、车型销量、成交净价或可验证修正、市场规模与 outside、稳定谱系与标签版本、核心属性、一组可信价格工具；micro-BLP 至少补一类微观矩（第二选择、标签阅读与工况识别、信任与主观预期、里程与充电条件、随机化信息解释）；企业操纵与工程适配要同硬件双测、道路实测、改款信息、广告与披露口径、批次日期，只有标签差时剩余项只能叫"无法由纯机械换算解释的标签楔子"。全国车型—月数据只恢复全国平均偏好与相对重配置，2022 年以后的城市上牌只能做后期异质性或模型外验证。

## 16. 数据事实（08-25 至 09-30 实测，引用前回原文件）

- **开题两份 dta 是"车型—年—总装工厂产量"面板加工信部能耗公示快照，不是销量**（`reference_cycle_switch_did_design.md`）。Codex 08-27 判决：数据工程 GO；燃油车探索性产量分析有条件 GO；**新能源车交错 DID NO-GO**（严格清洗后只有 5 个处理车型同时有处理前后观测）；**消费者需求 DID NO-GO**（切换年是由认证与数据存在性生成的年度吸收时钟，不是消费者可见标签日，且是产量不是购买）。

- **切换时点没有在楔子上自选择**（首现 WLTC 年份对楔子 b = −2.20，p = 0.66）；改革前趋势也不预测切换时点；但切换由年款换代节奏驱动，**与改款捆绑是头号威胁，同配置约束是必要条件**。
- **楔子几乎不能由属性预测**（全部属性加基线油耗 R² ≈ 0.30），放 `f(X) × year` 控制不会吸收楔子；不要用映射法预测楔子。
- **用户提出的外推法通过验证**：用车型自身切换前最后一个 NEDC 值作反事实，与双测金标准在 106 个共同车型上相关 0.8746、差值中位 0、sd 0.0329；样本扩到 379 个车型；测量误差约占楔子方差 24.6%（可靠度比 0.754），主设定限跨度 ≤1 年（`reference_wedge_extrapolation_and_uncertainty.md`）。中国实测楔子（约 +7%）远小于欧盟 NEDC→WLTP 的 +15% 至 +25%（Pavlovic 等 2018），论文必须正面解释。

## 17. 制度事实补充（联网核实，08-25）

- **ICE/PHEV 有强制截止**：GB 19578-2021 于 2021-07-01 起对新申请车型实施，2023-01-01 起在产车型必须满足，缓冲 18 个月。**BEV 是自愿切换**：装备中心 2021-04-09 通知允许按原标准或新标准检测。自选择方向在两侧都会伪造"标签变差需求降、变好需求升"，**实际切换日绝不能当处理时点**。
- **2023-01 同时是购置税减半到期**（2022-06 至 2022-12，2.0L 以下、30 万以下），税收资格与排量相关，必须放税收资格 × 月。
- **补贴按续航分档、双积分单车积分是续航的显式函数**，CLTC 换标跨档会改变实付价，这条机械价格通道直接击穿续航工具的排除限制（CLTC 强制日与补贴退出重叠约 15 个月）。**同期政策要测量后写进 p 与 mc，不要用固定效应吸收**，这也是"为什么必须上结构模型"的答案。
- 欧盟 2018 WLTP 过渡期标签只用 NEDC 值，没有面向消费者的标签冲击，不能当中国的先例照搬。

## 18. 识别：三条出路按 09-20 台账修订后的用法

1. **P15 设计母本**（同硬件、只有标签变）：可搬其固定效应结构、边界公式 `ΔWTP = ΔP − P_0·(ΔQ/Q)/η_D`（期刊版表 7；工作论文脚注 26 印作 `ΔP + ΔP·ΔQ/η_D` 是笔误，见 `extension_genealogy.md` B1）与"均值之比"偏误修正；但**连续剂量不替代对照组**，只识别每单位暴露的差异化响应。中国换标期产量可调，供给不像 GHvB 那样冻结，所以必须报这条边界而不是把 ΔP 直接当 WTP。
2. **P18 产品内跨维度**：只适用于结果本身是多个独立工程维度的问题（例如诊断工程适配发生在哪些属性）；**不能解决单一销量结果没有对照组的问题**，复制销量到多个维度会造成伪样本量。
3. **P05 模拟楔子工具**（政策换算规则 × 改革前属性）：**降级为候选工具**，预测值可能仍带可预测的工程适配或车型定位，必须单独论证相关性、排除限制、函数形式与生成回归量不确定性；P05 是讲义，不能单独承担论证。
- 08-26 双 agent 审核的三条更正仍有效：有可信 M 时 city × month FE 可估（但与市场层变量共线，二选一）；**WLTC 是更准的尺**，正确分解是 `Δlog L = w̄_d（纯换尺）+ (w_j − w̄_d)（车型特有信息）`，三种假说可分离；头条参数仿 Chetty–Looney–Kroft 定义在**共同换尺成分**上，`θ = (∂ln q/∂w̄_d)/(∂ln q/∂log π)`，分子用改革窗口里同类产品共同的纯换尺变化、分母用能源价格截面变异；理性且理解换尺者 θ = 0、完全名义幻觉时接近 1，[0,1] 的解释只对共同成分成立，产品特有成分 `(w_j − w̄_d)` 另作理性更新检验（与 `structural-model-building/references/mechanism_construction_and_theory.md` 第 3(c) 节同一定义；来源 `D:\blp-cycle-did-design\AGENT_REVIEW_SYNTHESIS_20260826.md` 第 14–20、177–197 行）；2022 年后城市面板里法定资格恒为 1，零处理变异。
- **动力不对称本身是识别来源**：改革符号在动力间相反，市场—时间层恒定项（含 M 的测量误差）被差掉。

## 19. 机制的专属检验特征（09-30，跨国类比只作设计启发）

| 渠道 | 专属特征 | 借鉴 |
|---|---|---|
| 资本化 vs 显著性 | 效应是否随里程放大；上险数据"使用性质"营运车作高里程组 | Hong–Kim–Verboven 里程微观矩 |
| 插混标签是否是真信息 | 理性更新下效应在家充难的城市更大，显著性下各地相近 | Gessner 等 (2025) 家充与电驱比例 |
| 显著性 | 同配置因 WLTC 从 x.9 跨到整数油耗处的跳跃（先排除按整备质量分档的门槛） | Kraft & Rao (2026) 左位数 |
| 信任 | 信任改的是需求对标签数字的斜率；2022 年燃油车约 30% 仍挂 NEDC，可同月比较新旧口径标签的权重 | Cho 等 (2023) 里程表执法（本机只有摘要） |
| 残值 | 进入广义价格、改变平均效用；二手车市场成熟度可作判别检验；有残值担保的车型链条被切断 | 记忆 `reference_cycle_switch_resale_channel.md` |
| 续航不便 | 插混主处理组上偏弱；BEV 剂量只有 +4.7%（6 车型），本次改革里大概率不可识别，论文应主动交代 | Barwick 等 (2026) 续航焦虑 |

福利与环境：插混全寿命外部性与燃油车几乎无差（P08 表 2，美国口径，量级不可移植），而插混是冲击最大的一类，把消费者推离插混在环境上未必是损失；更准的标签可能扩大扭曲方差（Allcott 等 2025 AER），福利部分要报方差。
