## 1. Decisions owned by this agent

1. **最小扩展单元**：在 payoff、belief、information set、constraint、strategy/contract space、market clearing 或 timing 中，只选择足以修复基准 tension 的最小变化。
2. **代理与行动**：明确谁在何时选择什么、观察什么、预期谁的反应；禁止无主语的“制度导致结果”。
3. **基准嵌套**：给出楔子为零、约束不绑定、信息完全、策略被限制或市场势力消失时如何恢复经典结论。
4. **时序与状态**：区分前定状态、政策/冲击、信号、行动、价格/均衡调整、结果与下一期状态；动态故事不得写成静态相关链。
5. **逐箭头闭合**：每个箭头必须说明改变的经济对象和符号/集合变化，不允许从“X 上升”直接跳到福利结论。
6. **比较静态**：先给主方向，再给决定强弱的 primitive，再给阈值/翻转或退化条件；不得把事后亚组相关当理论比较静态。
7. **预测梯度**：输出 `P`（模型命题）、`H_main`（可观察主假说）、`H_heterogeneity`（由理论斜率导出的异质性）、`H_boundary`（机制应消失/翻转之处）。
8. **形式必要性**：判断概念图是否足够；只有符号依赖战略互动、均衡反馈、动态承诺、选择/筛选或多重均衡时，才要求形式模型。
9. **观测痕迹**：将每个不可观察 primitive 对应到一个直接观测、制度处理、可辩护代理或需结构恢复的对象；不得把代理直接改名为 primitive。
10. **停止规则**：当扩展已嵌套基准、产生一个独特预测、一个条件异质性和一个失败条件时停止；额外模块必须由新决策需求触发。

## 4. Minimal baseline-extension protocol

### 4.1 One-page model skeleton

在任何代数之前填写：

```yaml

```

若 `single_changed_primitive` 无法写成一个可定位对象，说明模型仍是故事拼贴。

### 4.2 Benchmark nesting test

至少给出一个退化限制：

- 感知权重回到 1（p0001）；
- 切换不黏或正确模型路径被观察（p0012）；
- 信息共同性不变/战略作用归零（p0015）；
- 所有信息集按贝叶斯正确条件化（p0037）；
- 跨层约束不绑定（p0100）；
- 执行摩擦或市场势力之一消失（p0021/p0082/p0098）；
- 网络效应、多归属或未提取剩余归零（p0033）；
- 比较边界外生不可调整（p0058）；
- 诊断性参数为零（p0018）；
- 策略空间重新限制为纯价格/数量（p0053）；
- 借券费对利用率无反馈（p0064）。

不能恢复基准的“扩展”可能只是另一个模型，必须说明为什么仍回答同一问题。

## 5. Arrow-by-arrow mechanism ledger

机制必须写成不超过七个主箭头，每个箭头填四列：

| Arrow | Acting agent | Economic object changed | Sign/condition and observable trace |
|---|---|---|---|
| 1. shock/rule -> information/constraint | 谁接收冲击 | belief set、预算、法律边界等 | 冲击如何被观察/测量 |
| 2. information/constraint -> private action | 谁选择 | FOC、IC、best response、entry 等 | 行动方向与退化条件 |
| 3. action -> other agents/market | 谁回应 | residual supply、network quality、price、outside option | 最近直接结果 |
| 4. response -> equilibrium state | 市场/机制 | clearing、shadow price、sorting、selection | 均衡或状态依赖 |
| 5. state -> outcome | 谁受到影响 | quantity、wage、price、belief、allocation | 主预测 |
| 6. outcome -> welfare/next state | 规划者/下一期 | incidence、future belief、capital、quality | 仅在必要时加入 |

质量门：任何一个箭头若只能写“因为 X 重要”，必须回到 primitive；任何福利箭头若没有资源/激励/外部性或分配准则，删掉福利主张。

## 6. Comparative-static and hypothesis ladder

### 6.1 Comparative-static matrix

```text
Primitive or policy changed:
Endogenous object first moved:
Direct sign:
Strategic/equilibrium response:
Net sign or threshold:
Moderator that changes a model slope/constraint:
Benchmark/vanishing condition:
Observable contrast:
```

优先输出以下形式之一：

- `sign-switch`：p0015、p0021、p0098；
- `attenuation/amplification`：p0001、p0082、p0018；
- `threshold/region`：p0012、p0033、p0058；
- `shape restriction/multiplicity`：p0064；
- `cross-layer spillover`：p0100；
- `state-dependent slope`：p0053。

### 6.2 Four prediction types

1. **P1 — model proposition**：在明确维护条件下，楔子改变哪个均衡对象。
2. **H1 — main observable hypothesis**：处理/制度变化后，哪个直接可见结果向何方向变化。
3. **H2 — theory-derived heterogeneity**：只使用会移动机制斜率、约束紧度或信息质量的 moderator。
4. **H3 — boundary/vanishing hypothesis**：在基准恢复、互补市场缺失、约束不绑定或行动不可调整处，效应应减弱、归零或翻转。

竞争预测不由本 agent定案，但必须给 `fragile_assumption_to_theory2`，让对抗审计有明确入口。

## 7. Reusable theory-building actions

### Action A — one primitive, two sides of the market

当楔子同时作用于需求和供给时，不能只写一侧。p0018 要求信念同时影响经理借款/投资和放贷者定价；p0082 要求产品需求与劳动供给共同决定边际条件。若只写一侧，定量符号可能错。

### Action B — make the omitted object endogenous

把“外部给定”升级为选择：模型选择决定数据（p0012）、法律边界由招聘调整（p0058）、企业选择供给函数（p0053）、借券利用率反过来改变费率（p0064）。但必须说明选择发生在何时以及谁能承诺。

### Action C — preserve a single bridge statistic

高维机制应寻找有经济含义的桥梁：跨层资源影子价格（p0100）、fee–utilization 形状（p0064）、残余供给斜率（p0098）。统计量必须来自模型条件，不能为简化事后发明。

### Action D — derive heterogeneity before seeing results

异质性变量必须在理论中改变：信息共同性/任务难度、关系 tenure、网络强度、多数群体比例、市场集中度、约束紧度或 uncertainty composition。只按数据可用性分组，不构成理论异质性。

### Action E — separate direct and equilibrium effects

先写直接行动，再写其他代理/价格反应，再写净效应。p0082/p0098 的关键正是直接 wedge 与跨市场反馈符号不同；p0058 的直接工资约束与长期隔离也不同。

### Action F — model-necessity gate

- 如果机制只是一项可定义的会计修正且符号透明：概念框架足够。
- 如果存在战略回应、跨市场/跨期反馈、筛选、反事实行动集、阈值或多重均衡：需要形式化。
- 如果需要量化潜在异质性、福利或大政策反事实：停止扩展并交给 structural specialist。

## 9. Failure modes and evidence boundaries

### Failure modes to veto

1. **Kitchen-sink model**：一次加入偏好异质、认知偏差、市场势力、搜索、网络和政策执行，无法判断哪个 primitive 负责结论。
2. **无代理箭头**：写“制度提高信息，因此创新增加”，但没人选择、没有信息集或最优条件。
3. **未嵌套基准**：新模型不能在清楚限制下恢复旧模型，却声称“最小扩展”。
4. **把调节变量当比较静态**：moderator 没有移动任何斜率、约束或后验。
5. **直接效应冒充净效应**：忽略竞争者、价格、排序、选择或下一期状态。
6. **均衡选择消失**：只报告最喜欢的分支，不交代最大参与均衡、稳定性、内点、唯一性或选择规则。
7. **由可能性跳到经验机制**：模型能产生一个模式不意味着数据识别了该模型。
8. **由动作变化跳到福利**：没有 incidence、资源成本或福利权重就宣称改善。
9. **精确公式幻觉**：不得依据 card 重建 theorem 编号、精确不等式或 OCR 可疑符号。
10. **把卡片当全文新读**：本轮只能标 `card-backed theory construction`。

### Evidence boundary

- 机制链和包装动作可由 bridge cards 支持作检索；文章专属正式命题须重开 PDF。
- `observable implication` 是模型导出的辨识痕迹，不等于因果识别。
- `heterogeneity prediction` 只有在 moderator 被预先映射到模型 primitive 时才成立。
- 多重均衡、临界点和福利排序的精确条件若未源核验，应标 `conditional/inference`。
